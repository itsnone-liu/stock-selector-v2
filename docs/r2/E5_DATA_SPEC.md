# E5 缺失数据规格说明（供采集/采购/投喂使用）

生成：2026-10-05 ｜ 用途：Round 2 证据族 E5「公开资金信号」个股级数据
现状：EM 源从本机网络全部超时/断连；akshare 1.18.49 无新浪大宗/同花顺龙虎榜接口。
已有：SSE 市场级融资余额日度 2021–2026；平安源个股融资比例（仅 2026-09-30 单日快照，4,104 股）。

## 通用要求
- 时间范围：**2021-01-01 → 最新**（越早越好，最低可接受 2024-01-01 起）
- 粒度：日度 × 个股（6 位代码）
- 格式：CSV 或 JSON 均可；代码保留前导零；日期 ISO（YYYY-MM-DD）
- 每批文件附简单 meta（来源、抓取时间、覆盖范围）；不接受无来源数据
- 优先级：① 龙虎榜 ② 大宗交易 ③ 个股融资融券 ④ 其余公司行为

---

## ① 龙虎榜（最高优先）
每日沪深交易所披露的异动个股席位明细。

| 字段 | 说明 |
|---|---|
| trade_date | 交易日 |
| stock_code / stock_name | 6 位代码/名称 |
| reason | 上榜原因（如"日涨幅偏离值达7%"） |
| side | 买/卖 |
| rank | 席位名次 1-5 |
| seat_name | 营业部/机构名称（**机构专用**是关键字段） |
| seat_type | 机构专用 / 沪股通 / 普通营业部 |
| buy_amount / sell_amount | 该席位买入/卖出金额（元） |
| net_amount | 净额 |

用途：机构席位净买入=evidence boost；连续上榜+机构买入=吸筹佐证；高位机构卖出=派发信号。

## ② 大宗交易
| 字段 | 说明 |
|---|---|
| trade_date | 交易日 |
| stock_code | 6 位代码 |
| price / volume / amount | 成交价/量/额 |
| premium_rate | 相对收盘折溢价%（负=折价） |
| buyer_name / seller_name | 买方卖方营业部（机构专用同上关键） |

用途：折价接筹+买方机构=吸筹佐证；高溢价=抢筹；持续大宗卖出=派发压力。

## ③ 个股融资融券（日度历史）
| 字段 | 说明 |
|---|---|
| trade_date | 交易日 |
| stock_code | 6 位代码 |
| rzye | 融资余额（元） |
| rzbuy / rzrepay | 融资买入额/偿还额 |
| rqye / rqyl | 融券余量/余量金额 |

用途：融资余额斜率=杠杆资金参与度；吸筹段融资骤增=游资 vs 机构区分；两融骤降=去杠杆出清信号。
（已有市场级 SSE 汇总+单日个股比例；需个股级日度历史补全。）

## ④ 公司行为类（P1，存在即加分）
回购公告/进展、重要股东增减持（人/金额/区间均价）、定增（发行价/锁定期）、限售解禁（日期/数量/占比）、质押比例变动、机构调研（日期/家数）。字段从简：日期+代码+类型+金额/数量+价格（如有）。
