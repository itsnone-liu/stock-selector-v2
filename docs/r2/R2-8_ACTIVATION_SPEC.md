# R2-8 Activation Gate — 预注册规格（冻结于执行前）

## 研究问题
在 T3+有效支撑（R2-7 CONFIRM 等价 cohort）的股票上，价格从「跌不动」转为「开始推进」的最早可交易变化是什么？**找转折，不找突破**。禁止复活 T4「收复 N 日新高」口径（已裁死）。

## Cohort（与 R2-7 完全同轨）
月末 bar 事件 t0（2021-01..2026-08），满足：500 日成本带存在 ∧ 结构未破（收盘<带下沿×95% 连续5日不存在于 t0 前60日）∧ T3（个股20日收益>板块20日累计）。**基线即 R2-7 的 T3 行**：ALL conv 29.2/brk 11.4；BULL 29.8/8.0；BEAR 25.4/29.3；21-23 14.6/10.5；24-26 32.6/11.6。

## 五个候选转折特征（t0 日收盘可观测，逐日数据计算，全部布尔）
1. `ER_TURN`：Kaufman 效率比 ER10(t0) > ER10(t0−10)（10日效率比自身抬升=运动变干净）
   ER10(x)=|close[x]−close[x−10]| / Σ_{i=x-9..x}|close[i]−close[i−1]|
2. `RS_TURN`：RS 斜率转正—— (stock20−sector20)(t0) > (stock20−sector20)(t0−10)，stock/sector20=20日累计收益（sector 用 l2 sector_eq 日累计）
3. `PB_SHRINK`：近10日最大回撤深度 < 前10日最大回撤深度（回撤收窄）
4. `HL_RAISE`：min(low[t0-4..t0]) > min(low[t0-9..t0-5])（低点抬升）
5. `VOL_THRUST`：单位量价格推进改善——|ret5(t0)|/(vol5/vol20) > |ret5(t0−5)|/(vol5' /vol20')（价格效率/量比的5日改善）

## 预注册组合（防组合钓鱼，仅此一个）
`COMBO = RS_TURN ∧ ER_TURN`（转折双确认：相对强度+价格效率同向）

## Outcome（与 R2-6/7 同轨，不换口径）
conv = fwd60 内 max(high)/close−1 ≥ +30%；brk = fwd60 内破位（收盘<带下沿×95% 连续5日）。

## 判定标准（冻结）
- 对每个单特征及 COMBO，与 T3 基线比：**conv 提升 ≥3pp 且 brk 恶化 ≤2pp** 为必要条件；
- 分层稳健：21-23 与 24-26 两时代方向一致；BULL/BEAR 方向一致（幅度可差）；
- 满足=PASS（该特征为 Activation 口径候选）；conv↑但brk恶化=SUPPORT_ONLY；否则 FAIL；
- **单次执行，不换参重跑，不逐特征调阈值**；缺失数据（sector 缺失等）事件按现有规则跳过并报告 n。
