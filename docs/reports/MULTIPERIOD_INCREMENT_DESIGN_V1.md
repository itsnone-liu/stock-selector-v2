## 1. 背景与研究问题

forward_y40_association_v1 结论: 固定模型下日线量能无稳定、明确的排序正增量（breakout/shrink 未检出; stabilization 微小负向点估计, 依赖性敏感）。

本阶段不推翻该负结果, 而是检验其**适用范围**:

- Q1(周价背景增量): 纯周线价格背景能否改善日线价格模型?
- Q2(日量条件增量): 掌握周线价格背景后, 日线量能能否提供额外信息?

两个问题分开回答, 不引入更细粒度交易数据。

## 3. 特征集冻结

### 3.1 A0 / B0(继承 v1, 不变)

A0 = v1 冻结价格集(breakout/shrink/stab 三时点各自); B0 = A0 + v1 日线量能特征。作为原基准与旧实验对照。

### 3.2 A1 = A0 + 纯周线价格背景(量价归属已逐字段核实)

**入选(全部纯价格、观察日已知、面板现成列)**:

| 特征 | 定义 | 来源核实 |
|---|---|---|
| momentum_context_positive | 前两周完整周 cc 均>0(布尔; None=数据不足→按缺失处理) | weekly_features.py L196 注释+contracts.py L92 |
| week_realized_pct | 当周已实现涨幅(部分周按已实现值) | 纯价格 |
| prev_week_cc_pct | 前一完整周收盘涨幅 | 纯价格 |
| prev2_week_cc_pct | 前二完整周收盘涨幅 | 纯价格 |
| l_eff_redef | \|prev_week_cc_pct\|(从价格重算, 不用面板 l_eff) | 见下排除说明 |

**排除(量价混合, 2026-09-22 复审确认, 引代码证据)**:

- weekly_passed / weekly_base_pattern / weekly_eligibility_state: 双阳效率 `t_eff=|tc|/tv_ratio` 含量比(weekly_features.py L37), veto v4.0 用 amount/volume×1.5(L12, L58-66), 通过/否决/滞涨逻辑继承量能
- t_eff: 本周涨幅除以量比 → 量价混合
- l_eff: 数值=前周涨幅(纯), 但面板可用性依赖形态计算分支 → 重算为 l_eff_redef
- theory_stagnation_flag: 含 scaled_vol>prev_vol → 量价混合
- current_momentum 六分类: 量价混合(折算量比 0.8/1.5 阈值), 不整装

**月线**: 保留生命周期入池门槛(v1 口径), **不新增月线强度指标**。理由: 观察事件月线状态 100% in, 本样本不能比较多头/非多头; 均线发散/月线涨幅/趋势时长等变量未经覆盖与定义审计, 不入当前设计(复审§1.2)。

## 4. 模型与折(全部继承 v1 冻结)

Ridge α=1.0 闭式(截距不惩罚); 折内中位数插补(全缺失列→0 并记录); 仅训练集标准化; 折 b19–b22(训练=obs_bucket<测试桶 AND label_avail_day<折首日, 严格); MIN_TRAIN=200/MIN_TEST=50; MIN_STK_PER_DAY=10; seed=20260919; BOOT=2000; 标签=Y40(v1 口径); 去重规则与 dedup 门禁同 v1。

## 5. 主比较与推断

### 5.1 六项主比较

每时点 s∈{breakout, shrink, stabilization}:

- ΔIC_周价(s) = IC_{A1}(s) − IC_{A0}(s)
- ΔIC_日量(s) = IC_{B1}(s) − IC_{A1}(s)

统计口径全部同 v1(同日截面 Spearman IC, 折=等权日均值, 总体=折有效日数冻结加权)。

### 5.2 多重检验

六项主比较统一 Holm(家族=6)。bootstrap: 40 日有放回块重抽(折内独立+原始 w_f 加权, b0be101 修正版) + 股票块频数权重敏感性。

### 5.3 预定义分组诊断(单独声明, 不属主检验)

按纯周线价格状态分组(只用观察日已知价格状态, 严禁按未来收益分组):
- 分组变量: momentum_context_positive(True/False/缺失单列)
- 诊断内容: 各组内 ΔIC_日量 点估计与区间; 组间差异按样本或有效日数不足则报告**不可检验**, 不合并不挑选
- 目的: 回答"日量增量是否只在某种周线价格背景下存在"——总体比较(§5.1)本身无法回答此问题

## 6. 反例与门禁(新增)

1. A1 零量能审计(2026-09-22 二轮口径): 检查**入选字段的实际计算来源**——五个 A1 特征不从 weekly_features.py 的混合输出取列, 而从日线 close 独立重算(聚合过程只触碰价格列); 门禁=特征构造函数的源审计(输入列白名单)+运行时断言(重算值与所用输入仅含价格)。禁止对整文件做 volume 字符串扫描(混合文件必然误报)。
2. B0 复现两层门禁(2026-09-22 二轮修订): ①三时点最终 ΔIC 四舍五入至五位小数须与旧归档一致(−0.00463/−0.00017/−0.01103); ②四折未舍入 IC/MSE 等指标与旧 JSON 完整精度逐项比较, 容差 1e-10。两层都过才算复现(旧归档仅五位小数, 不能与未舍入值直接做 1e-10 比较)。
3. 恒等 bootstrap(exact==点估计)与 A,A,B 有放回反例(继承 b0be101 测试)
4. 面板对齐断言: 分析事件面板匹配率=100%(缺失>0 即 fail-fast)
5. 口径断言: 阶段事件数与股票-日期组合数分开落盘, 报告不混称
