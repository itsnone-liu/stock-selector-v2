## 2. 设计支柱(待细化后冻结)

### 2.1 抽样单元(候选, 预注册时定一)

- S1 生命周期对照: 每个首突生命周期匹配 k 个同期未突破段(同月池窗口),
  以段为单元——消除段内日相关, 损失日粒度
- S2 风险日对照+聚集校正: 保留日粒度, 按股票块/日期双聚类推断
  (block bootstrap 继承, 但须先证块结构充分)
- S3 同日截面配对: 每个首突日, 取同日风险截面(未突破股)对照——
  消除日效应, 需同日风险股充足(预检)
倾向: S1 为主(单元干净), S2/S3 作敏感性——**v0.2 定稿前须用户选型**。

### 2.2 终点与竞争风险

- 对照单元终点: 未突破段按实际 end_day 终止(月线退出/结构破坏/观察期满/
  数据末——end_reason 分层披露); 右删失段(256)处理方式预注册
- 结果窗口: Y40 同任务一口径(40 指数交易日), 对照日 t0=匹配日(非 anchor)
- 竞争风险披露: "未突破"是删失状态而非"永远不突破"——解释边界预注册

### 2.3 选择偏差(必须预注册)

- 生命周期由月线入池筛出→对照"未突破"≠随机股票日; 背景变量(月强/周结构)
  在突破组与对照组的分布差异必须先描述(无结果变量的平衡表), 后建模
- 禁止: 事后按后续表现调整匹配变量

### 2.4 检验(占位, 覆盖预检后冻结)

  平衡表样本、双聚类块结构; 多数不足→直接报 STOPPED, 不跑主检验
