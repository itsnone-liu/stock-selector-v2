## 4. 因子层落地方案（依规范 §5.1）

```
F_t     = hfq_t / raw_t          # baostock 后复权 / 本地（=baostock）不复权
P_adj_t = raw_t × F_t = hfq_t     # 恒等于后复权序列
R       = P_adj 比 = hfq 比 = 总收益复权收益（分红再投资口径，规范 §5.1）
```

- 除权日识别 = F 跳变日（干净单日跳变，容差 1e-4 即可稳定识别）
- 无公司行动 → F 延续前值（数据结构天然满足：段内恒定）
- **容差分层（冻结）**：
  - 同源重复计算（`raw × (hfq/raw) == hfq` 重算链路）→ `1e-9`
  - 非除权日 F 稳定性、本地 raw vs BaoStock unadj、第二源交叉验证 →
    按源精度 `1e-4`（外部序列舍入不入 1e-9 判据，避免假失败）
  - 样例（单股、无舍入冲突）实际为 0.00000%，全量以 1e-4 为门禁上限
- baostock `adjustflag=2`（前复权）仅作**同一供应商内部一致性检查**，不算第二独立源；第二独立源另行选取（Tushare 有明确"分红再投"声明，BaoStock 的总收益语义仍需手工账本+独立源双重实证）

### 6.3 腾讯 hfqday 判定：路径污染，不用于 F 构造

sh.600000 实证（2021-01-04 ~ 2026-09-18，1,386 交易日）：

- corr(ΔF/F, Δraw) = **-0.9183**（标准事件驱动后复权应 ≈0）

  vs BaoStock 真实除权日 6 天
- 结论：其 hfq 为动态锚定/逐日再投类算法，**事件间收益恒等式被破坏**，
  不可用于 `P_adj = raw × F` 构造；unadj 序列正常，保留为第三方参照
- 新上市股（sh.601091，2026-09-17 IPO）hfq 请求回退 `day` key，
  即 hfq≡unadj、F≡1，符合无除权事件语义
