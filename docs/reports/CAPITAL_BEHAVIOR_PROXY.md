# capital_behavior_proxy_v1 — 资金态度代理指标独立信息验证(开发期)

**核心问题**: 控制价格位置/回撤/提前量后, 日线量能是否仍提供独立路径信息?
市场微观结构视角: 价格影响也来自订单不平衡/深度/撤单——日线量能至多是资金态度的**代理变量**,
本阶段验证代理是否可用, 不从日线反推资金意图。

## 一、冻结设计

- 集合: A=价格基准(距突破位/回撤/近期收益/lead_td); B=A+量能; C=B+结构(波动/位置/预定义交互)
- 去重: sh_volratio5≡volratio5 全等(留前者); rvol20=收益波动率→归 C
- 同活跃风险集(eligibility_riskset: 6779/3559/27175)/同折/同模型(逻辑回归, 训练折拟合, seed 20260919)
- 分层边界事前固定: near=|距突破位|≤3%; 反弹≥3%=有效止跌; 不按结果挑组

## 四、第三问: 是否跨期稳定?

- B−A 增量: 三时点逐折均无稳定提升(见上表 CI 全跨 0)。
- 条件效应: 仅 shrink/below 一层四半年同向; 其余状态半年翻转。
- A 集本身跨期稳定: shrink 0.64-0.73, stab 0.71-0.74, breakout 0.49-0.60(b19 近随机)。

## 四b、更根本的问题: 标签由未来价格位置定义(验收修订, 2026-09-21)

本阶段结果揭示: 当前标签(path_binary)就是"未来是否重新达到突破价", 而观察日价格距该
位置的远近天然包含大量相关信息——near 层正类率 0.234 vs below 层 0.537, 这一差别首先
是价格状态, 不是资金身份。A 集的高 AUC(shrink 0.64-0.73)主体正是这种与标签定义同源的
价格路径信息。成交量能否在**相似价格状态下**提供额外信息才是研究初衷——本阶段回答是:
日线量比未能证明。若继续资金视角, 下一步应先明确一个与研究初衷更接近、但**不由突破价
直接定义**的结果指标(后续趋势延续/未来相对收益/回撤风险), 再决定需要什么数据; 不宜
立即投入成本采购逐笔/订单簿数据, 否则仍会围绕"距目标价格多远"打转。

## 五、假设清单

**探索性线索(不作机制支撑)**:
- 失守后缩量-never 同向(b19-22): 无法与层内残余价格状态混杂区分, 仅供后续以非价格
  位置标签重测时参考。

**未得到支持**:
- H1 量能独立信息: 三时点 B−A CI 全跨 0——日线量比/量能恢复不含独立于价格的位置信息;
- H2 缩量条件分化(near/止跌状态下量能重定向): 各层半年方向不稳;
- 此前'突破日量能扩张→never'关联=价格过热的共线代理, 非独立量能证据。

**目前无法识别**:
- 日线粒度下的真实资金态度(惜筹/动能增强的行为层): 日线成交量分辨率不足;
  若需继续该机制, 须引入逐笔成交/订单簿/持仓类数据, 而非继续挖掘同批日线特征。

## 六、结论与边界

1 现有日线量比在这项特定路径识别任务中**没有证明自己的独立价值**(B−A 三时点 CI 全跨 0);
2 '量价特征区分路径'的主体是与标签定义同源的价格位置信息;
3 真实资金态度能否从交易数据中识别, 仍是**开放问题**——本阶段只划定了日线量能在这
  一标签下的分辨率边界, 不构成对资金视角的否定。
边界: 开发期; 非因果; 非收益证明; 未调阈值未重选模型; 复权人工核对例外保留。
