## 1. 五问对答案（T6 开工令 Q1–Q5）

**Q1（E0-E3 梯度在 validation/confirmation 是否仍有结构差异？）**——有，但语义修正：
E 梯度是**初始风险预算结构**而非收益等级（C502）。风险轴（median_mdd / p95 / p05 /
p_terminal_failure）双段双 cluster 全显著=最稳健块；收益轴口径依赖（p25 最稳，median
conf 段 T0_date 跨零）；E3≠"收益最高档"。

**Q2（REDUCE→ADD 是恶化→修复的敞口循环吗？）**——**不是**（C501，本阶段最重要修正）：
恶化**程度**触发资本收缩且分层预测结局（深恶化 3–6 倍于浅恶化）；ADD 中位 2 天、价格
更低、指标未修复——"等待修复确认"的读法被数据拒绝（C207），替代描述为快速低位回补。

**Q3（失败发生在哪一段？）**——F1 早操作 + F3 假恢复 + F6 残差（C503）；EXIT 缺失
（F4）与数据缺口（F5）边缘；F2（识别迟）= 首中分类结构零（≠机制不存在）。E2 张力
多路径：F6 ~45% / F1 ~30% / F3 ~28%，形态为 PAINFUL_WIN 型（终亏更少、带伤到末日
更多）。

**Q4（市场/板块 regime 的作用？）**——市场态与循环结局强相关（val 弱市 67% 无恢复）
但段间形态不同；**预注册 breadth/new-high 三档未区分同签名真假恢复**（范围=所测表示）；
E3 风险方向六层全保持；sector 交互不可分析（NON-PIT 缺失，≠无效应）（C504）。

**Q5（Policy V1：哪些冻结、哪些仍是假设？）**——见 §3 决策映射（C508）。

## 2. 机制链（修正后的冻结叙事）

```
初始 E-class（T6.1）
  = 初始风险预算结构：E1→E2 收益/效率（口径敏感），E2→E3 风险塑形（最稳健）
        ↓
状态恶化（T6.2）
  恶化幅度分层：轻度 → REDUCE → 继续回落 ~2 天 → 快速低位回补（ADD）
                重度 → REDUCE → NO_RECOVERY（val 弱市 67%）/ EXIT（仅 conf）
        ↓
假恢复（T6.3）
  危险信号不是"跌得深"而是 REDUCE 日的"热"：当日反弹 +0.013、efficiency 更高、
  价格高于 ref20、换手更高（双段 Holm 显著）——短期转强 ≠ 结构修复
        ↓
外部环境（T6.4）
  breadth/new-high 市场 regime 不区分同签名真假恢复；与恢复池构成相关；
  E3 风险方向跨 regime 保持
```

**被修正的原始故事**："恶化 → 减仓 → 等修复确认 → 加仓"。
**冻结的替代结构**："恶化程度触发资本收缩；系统随后较快恢复暴露，但短期反弹本身不能
证明结构修复，因此产生 false recovery。"

## 3. Policy V1 决策映射（C508）

**冻结可用**（证据充分）：
1. E-class 作为**初始风险预算维度**使用（非收益评分）；
2. 暴露动态=恶化触发、幅度分层结果的资本收缩机制；
3. 失败结构定位（ADD 段+早操作段主导，EXIT 缺失边缘）——资源应流向 ADD 时机研究而非
   EXIT 补救。

**仍是假设**（不得作为设计规则引用）：
1. ADD 时机的任何"修复确认"判据——数据表明现行规则中不存在该确认（若未来设计修复
   判据，是**新规则设计**，需走 T7 预注册，不是 T6 结论的延伸）；
2. 任何真假恢复区分器（未找到）；
3. sector 条件化行为（不可分析）；
4. E2 conf 张力的机制（多路径描述性，无交互对比）。
