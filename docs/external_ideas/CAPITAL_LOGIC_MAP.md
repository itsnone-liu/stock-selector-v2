# 资金逻辑地图 v0.1 —— 量化思想按「成本—吸筹—筹码—推进—浮盈—兑现」重分类

> 依据：用户 2026-10-14 认可的资金逻辑上位框架（资金获利闭环 / 资金逻辑六问 / 三层分类 / 资金逻辑卡 / 假说驱动验证）。
> 定位：所有外部量化思想的**统一上位分类层**，下辖 EI 接口层（`EI_PLAN.md`）与 Round 2 研究主线。
> 铁律：本图只做分类与准入，**不改变任何已冻结裁定**。已关闭项在图中的位置=其归宿，不因入图而重开。

---

## 0. 使用规则

1. **第一问永远是**：它刻画资金获利链的哪个环节？——不是「IC 多高」「回测多漂亮」。预测能力只是对机制是否真有价值的后验检验。
2. **三层定位**（每个思想入图先定层）：
   - **L1 机制量**：直接测资金行为/结构的量（成本分布、持仓变化、价格冲击本身）
   - **L2 痕迹**：行为留下的可观察痕迹，需要「痕迹→行为」映射假设（量价形态、动量、突破）
   - **L3 数学**：本身无市场含义的工具（FFT / PCA / 小波 / 聚类 / HMM / Kalman / NN / boosting）。永远「资金问题 → 需识别的现象 → 选工具」，禁止反向（看到工具找股票）。
3. **裁决动词**（沿用 EI-0 并扩充）：
   `ALREADY_COVERED`（现有模块已覆盖）｜`CONTRADICTED`（与已验证结论矛盾）｜`OPEN_GAP`（体系真空白）｜`POTENTIAL_INCREMENT`（可能增量，须过卡+检验）｜`STAT_CANDIDATE`（统计候选：只作控制/条件/对照变量，不进核心）｜`EXEC_ONLY`（执行工具）｜`ARCHIVED-CLOSED`（已关闭不重开）
4. **硬门**（六问中两道）：
   - Q2（链上环节）或 Q4（为什么未来应有收益差——机制）答不出 → 一律 `STAT_CANDIDATE`；
   - Q6（相对现有模块新增什么 = existing_baseline）答不出 → 不研究。

## 1. 主链与体系坐标

资金获利闭环（**适用模板：中长线主力资金**）：

```
资金来源 → 建仓成本 → 吸筹 → 筹码结构 → 推进 → 浮盈 → 兑现 → 撤退
                                    └────────────── 背景层（体系外，定仓位不定个股）──────┘
```

**资金类型修正维度**（同一条链，不同走法——判读任何痕迹前先问"这是哪类资金的痕迹"）：

| 资金类型 | 链的走法 | 体系对应 |
|---|---|---|
| 主力中长线 | 全链走完，成本→兑现间隔长 | R2-4 路径 A（长期吸筹→突破） |
| 游资短打 | 链压缩：进场即推进即兑现，吸筹≈一瞬间 | 路径 B（快速换手→整理→突破） |
| 机构增仓 | 无控盘意图，兑现由申赎/考核驱动而非利润空间 | 路径 C（机构增仓→缓趋势→加速） |
| 被动/配置资金 | 无兑现环节，进出由外部指令决定 | ETF/指数成分机械流（背景层素材） |
| 政策资金 | 目标非利润最大化，退出逻辑特殊 | 路径 D；NATIONAL_TEAM 与 POLICY_CAPITAL_PROXY 不可混叫 |

## 2. 六格详表（每格=含义 / 体系内对应物 / L1 / L2 / 同痕异因 / 裁决注记）

### ① 成本（cost basis）——体系的锚
- **含义**：在场主要持仓的建仓成本分布。成本决定利润空间，利润空间决定兑现冲动。
- **体系对应物**：CD-5 成本上下文（C0-C3 四层 observable cost structure，50 桶加权直方图）、Cost Band、Cost Support（已验证 WHERE 判定）、R2 cost_center/P25/P50/P75。
- **L1**：volume-at-price 分布；大宗成交价、定增/回购/增持价（**精确公开成本，直接观测**）；机构增仓成本（季度持股差×区间成交分布，model_derived）。
- **L2**：放量堆积位、价格回踩某区域的反应。
- **同痕异因**：放量堆积位可能是套牢盘而非主力成本（下跌派发同样堆量）。**区分变量**：堆积后的路径——吸筹后卖压衰竭/拒绝跌回 vs 派发后阴跌。
- **注记**：CD-0 冻结铁律——成本=observable cost structure，永非庄家真实成本；直接观测 vs 模型推导必须标注。「新带=支撑」已在关闭清单（Cost Support 判定取代）。

### ② 吸筹（accumulation）——Round 2 主线的核心格
- **含义**：资金进场但控制价格，换取筹码。
- **体系对应物**：R2 latent states ACCUMULATION / ACCUMULATION_MATURE；lifecycle 的 ACCUMULATION_CONSISTENT / MATURE_ACCUMULATION / RE_ACCUMULATION_CONSISTENT；CHIP_LOCKING 五证据链。
- **L1**：股东户数下降+户均持股升、十大流通股东变化、机构持仓增（季报，滞后）；知情交易类量（PIN/VPIN、隐单/拆单——A股可得性差，降级使用）。
- **L2**：缩量横盘/缩量回调（卖压衰竭）、换手结构异常、量累积与价格背离、波动收缩。
- **同痕异因**：缩量横盘可能只是无人问津（根本没有资金）；机构增仓可能是被动配置。**区分变量**：后续推进效率（有备资金突破时 impact 高）+ 户数/机构/成本带多证据矩阵——这正是 R2 用证据矩阵+概率而非单指标的原因（同痕异因是结构性识别问题，不是工程问题）。
- **注记（防重开）**：Round 1 终审已冻结「吸筹**单信号** NO-GO」「户数=看涨信号 NO-GO」「单峰密集吸筹 ARCHIVED」。吸筹作为**多证据概率推断**由 Round 2 主线承担；不得以「换个吸筹指标」方式重开单信号路线。

### ③ 筹码结构（supply structure）
- **含义**：当前供给方是谁、锁不锁、上方悬顶多少。
- **体系对应物**：FLOATING_SUPPLY_PRESSURE（上方套牢+高换手+机构减+户数升+反弹放量滞涨）、CHIP_LOCKING 反面、解禁/大宗/增减持日历。
- **L1**：股东户数/户均、十大流通集中度、机构持仓变化、解禁日历（**硬日历变量，可精确知道**）、volume profile 上方供给密集区。
- **L2**：换手率（松动度）、上涨中的换手结构、缩量上涨（供给诊断）。
- **同痕异因**：高换手=换手接力（弱手→强手，利好后续）vs 派发（强手→弱手）。**区分变量**：价格位置相对成本带 + 换手后 impact 变化——脱离成本位置谈换手无意义。
- **注记**：缩量上涨=HOLD 供给诊断（DIAGNOSTIC 保留，优先级低于 HL_RAISE）；户数作为**筹码供给证据**在 R2 使用（作为看涨信号已关闭）。

### ④ 推进（markup）——外部思想最密集、冗余最高的一格
- **含义**：新增资金持续克服卖压，把价格推离成本区。
- **体系对应物**：MARKUP_READY / MARKUP_ACTIVE（R2）；lifecycle MARKUP；T1-T3 tier（已验证 WHAT）；海龟式突破已被吸收为启动/推进确认；EI-5「更少成交推更大位移」（activation 唯一可重挑方向，DEFERRED）。
- **L1**：price impact / Amihud（由痕迹估计的机制量代理）、trade initiation、VWAP displacement、liquidity consumption；OFI（分钟级近似）。
- **L2**：动量 / RS / RPS、放量突破、up/down volume 结构、高低频量价 diff（hf-lf）、趋势强度。
- **同痕异因**：放量突破可能是对倒/假突破或被动指数机械买入。**区分变量**：突破后持续性 + 回踩时卖压（真突破回踩缩量）+ impact 衰减率。
- **注记**：**Q6 在此格杀掉的东西最多**——几乎所有趋势类指标住在这里，多数是同一信息的重复表达。判例：RPS（EI-3 FAIL，T3 充分 = ALREADY_COVERED）。EI-5 提示：只有**信息域不同**（竞价/分时 timing）才算真新增。

### ⑤ 浮盈（unrealized profit）——已有一个生产模块的格
- **含义**：持仓者的利润状态=兑现冲动的强度。成本→兑现的桥梁。
- **体系对应物**：EI-2 DTC-Q5 REDUCE（**已 PASS 进生产**——本格第一个已验证模块）、倍危（多周期过度扩张）、cost band 位置、HL_RAISE 风险层。
- **L1**：获利盘比例、浮盈分布（基于 observable cost structure 的 model_derived）、distance-to-cost、ATR 归一化延伸度。
- **机制桥**：处置效应——获利盘越大卖压越大；也是动量崩溃的一种候选解释（假说，不是结论）。
- **同痕异因**：涨幅大 ≠ 主力浮盈大（可能主力已走、散户追高）。**区分变量**：用 distance-to-cost 而非裸涨幅；筹码堆积区是否仍锁定在场内。
- **注记**：裸涨幅/超买振荡器类 ARCHIVED（S001 被 Cost Support 替代）；本格关键词组：disposition effect / unrealized gains / profit taking。

### ⑥ 兑现（distribution）——最难识别的格，定位=风控而非选股
- **含义**：大资金卖出落袋。主力隐藏动机最强的一环。
- **体系对应物**：DISTRIBUTION_RISK（R2/lifecycle）、HL_RAISE、BROKEN 硬退出（STRUCTURE_BROKEN）、EI-2 REDUCE。
- **L1**：大宗折价、增减持公告、机构席位卖出、异常换手反转（abnormal turnover reversal）、知情卖出。
- **L2**：放量滞涨、高位巨量换手、上影密集、拉尾盘。
- **同痕异因**：高位放量换手=派发 vs 换庄接力。**区分变量**：换手后 impact 衰减率 + 是否仍拒绝跌回成本带。
- **注记**：龙虎榜作为**组合选股信号已关闭**，但龙虎榜数据在 R2 数据体系 E 中保留作事后 evidence/归因——关闭的是信号用途，不是数据用途。本格体系内定位=出场/减仓/风险变量（HL_RAISE / REDUCE / BROKEN），不是选股信号。

### ⑦ 撤退（exit aftermath）
- **含义**：资金离场后的路径——缩量阴跌、流动性枯竭。
- **体系对应物**：DECLINE / STRUCTURE_BROKEN、BROKEN 后续跌验证、用户裁定「连续放量下跌等周动能负向不考虑交易」。
- **L1/L2**：Amihud 恶化、买卖价差、成交萎缩、负向动量。
- **用途**：负向池过滤与空仓条件，不产出买入信息。

### 背景层（体系外——定仓位，不定个股信号）
- **体系对应物**：Market regime（五日多数票）、P3 regime 乘数（BULL 1.0 / BEAR 0.5 / OTHER 0.75）、板块资金（L2/SW2）、ETF 份额、Breadth（EI-1 B50 **PASS→生产**）。
- **L1 素材**：国家队 registry、北向（盘中实时披露 2024-08 起停发，仅剩日度总量级）、融资余额、板块 ETF 申赎。
- **原则**（用户裁定）：背景层只决定整体仓位；不得借市场/日期聚类修改个股信号逻辑。

## 5. 准入流程（六问流程化）

1. **只填卡，不写代码**。一张卡 30 分钟填不完=还没理解，先入 STAT_CANDIDATE 池。六问是筛子，不是仪式（Production Review Mode 教训：防止框架本身仪式化）。
2. 六问 + 定格子 + 定层级（§0-§2）。
3. 硬门：Q2/Q4 不过 → STAT_CANDIDATE；Q6 不过 → ARCHIVED。
4. 过门 → 设计**条件区分度检验**：在已识别的不同成本/筹码/生命周期状态中检验区分能力。真机制指标的效应应**随状态变化**（低位成本格强、高位浮盈格弱）；处处等强 = 测的不是资金，是共同因子。
5. 一次预注册主实验 + 必要独立验证；禁改周期/阈值/换名重试（EI 停止线原样适用）。
6. PASS → 入核心/生产并登记失效监控变量；FAIL → 归档不救。

验证顺序固定：**资金假说 → 可观察痕迹 → 量化指标 → 历史验证**，不可反向（与 R2 matched-control / probability-lift、Round 1 G0-G5 边际贡献同构）。

## 6. 框架自身的元检验（防教条的最后一道闸）

框架要求每个思想可否证，框架自己也必须可否证：每完成约 10 张卡（或每年）复盘——过卡进入检验的思想，其 PASS 率与生产贡献是否**显著高于** STAT_CANDIDATE 池与基线？若长期无差别，说明「主力资金链可从公开痕迹识别」这一前提本身衰减，框架须降级或修订，而不是继续发卡。

- **关闭的是用途不是数据**：龙虎榜/户数关闭信号用途，数据仍按各自格子的 L1 清单收集。
