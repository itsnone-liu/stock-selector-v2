# TDX 自立门户：除权 + 实时 数据需求规格（逆向目标定义）

> 2026-10-21 老刘亲自逆向通达信协议（除权/实时），本文档定义系统侧的确切数据需求。
> 背景：腾讯 fqkline web 接口双域 WAF 封禁（10-19/10-20 多次实锤），全市场拉取不可持续，
> 自立门户从优化升级为刚需。pytdx 参考实现：`/usr/local/lib/python3.10/dist-packages/pytdx/`

## 一、除权除息（XDXR）—— qfq 自算的唯一事件输入

**用途**：qfq 前复权自算；overlap_qfq_mismatch 审计对照基准。
**覆盖范围硬要求**：全市场 5430 只，**含北交所**（腾讯渠道覆盖 bj，自立门户不能丢）。

### 字段需求（对照 pytdx get_xdxr_info 语义）

| 字段 | 必需性 | 语义与口径陷阱 |
|---|---|---|
| 除权除息日（year/month/day） | 必需 | 精确到交易日；**同日多事件（分红+送转常见）必须合并成单因子** |
| category 类别码 | 必需 | 仅影响价格的类别参与复权（1=除权除息/分红，2=送配股上市，…） |
| fenhong 分红 | 必需 | pytdx 口径为**每10股**派现（0.50=10派0.5）→ 每股= fenhong/10，税前口径 |
| songzhuangu 送转股 | 必需 | 每10股送转 → 因子 = 1/(1+送转/10) |
| peigu 配股 + peigujia 配股价 | 必需（发生时） | 每10股配股数 + 配股价；配股因子需前收价参与 |
| qianzongguben / houzongguben 前后总股本 | 推荐 | 自洽校验：hou/qian − 1 ≈ songzhuangu/10 |
| panqianliutong / panhouliutong | 可选 | 流通股本变动，换手率计算可能用得上 |

### 计算语义（对拍目标 = 腾讯 qfq 口径）

- 除权因子 factor = (前收 − 每股分红 + 配股价×每股配股) / (前收 − 每股分红) × 1/(1+每股送转)
- qfq 价 = 原始价 × 该日**之后**所有事件的因子连乘（前复权 = 向历史回溯调整）
- 对拍容差：逐 bar diff ≤ 0.01 元（float 四舍五入口径）

### 现成验证样本

1. **600125**：三事件 2025-11-14（10派0.5）、2026-06-12（10派0.71）、2026-10-13（10派0.5）；
   本地 `data/cd/daily_fullmarket/600125.json.gz` 存腾讯 qfq 全史，可逐 bar 对拍
2. **117 只 10 月除权票**（update_2026-10-19.json overlap 清单）= 批量对拍池

**验收线**：随机抽 50 只近一年有除权事件的票，自算 qfq vs 腾讯 qfq 重叠区 diff≤0.01 占比 100%。

### 强度要求

每晚增量（只拉当日有事件的票）+ 一次全量历史回填（5430 只）。逐只拉取强度远低于腾讯 web 全市场 kline，协议通道（7709 行情端口）无 WAF 封 IP 概念，社区常规操作。

## 二、实时行情 —— 替换腾讯实时接口（与 WAF 同源风险）

**用途**：盘中 1135/1355 轻扫（~1076 只池）、盘中板块选股（换手率>2% 硬过滤）、
stock-vs-sector 对比、EI-5P 10:01 窗口采集。

### 必需字段

| 字段 | 用途 | 备注 |
|---|---|---|
| 代码 + 市场 | 定位 | sh/sz/bj |
| 最新价 | live px、成本带计算 | — |
| 昨收 | 算涨跌幅 | 不给昨收则需直接给涨跌幅 |
| 涨跌幅 | 展示/排序 | — |
| **换手率** | 板块选股硬过滤（<2% 剔除） | 关键字段：通达信 quotes 不直接给 = 成交量÷流通股本；逆向时须定流通股本来源（每日快照表 or TDX 股本数据） |
| 名称 | 展示 | — |
| 时间戳 / 交易状态 | 区分盘中/停牌/收盘 | 停牌票必须可识别 |

### 硬性约束

- **批量性**：单次 ≥60 只（腾讯现用 60-80/次；mootdx get_security_quotes 单次 ≤80 只）。
  5430 只盘前全刷 ≈ 70-90 次请求，可接受；逐只接口不可接受。
- **频次**：快照级即可——每天 4 时点（09:28 竞价 / 10:01 / 11:35 / 13:55）+ 选股按需。
  **不需要** tick 级、分笔、分时（现有策略不消费）。

### 现状提示

mootdx 实时通道（`pytdx/hq.py:73 get_security_quotes`）生产环境已在用（换手率数据源），
稳定未封。逆向第一问：通达信实时协议是否即 pytdx 此实现——若是，实时侧零开发，
仅需把批量调用固化为盘中接口的腾讯备援。

## 三、优先级

1. **除权**（qfq 自算的卡点，没有它自立门户不完整）
2. **实时批量 quotes**（替换腾讯实时接口）
3. K线拉取：tdx-protocol 已验证可通（/tmp 克隆实测 1792 根/秒），作备胎；
   主力读本地 TDX 镜像（/root/tdx_data，零网络请求）
