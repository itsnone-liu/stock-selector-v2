## 解释边界

AVWAP 是事件锚定成交重心，非"主力成本"；gap 不识别持仓者意图；全部为机制关联描述，非因果、非交易信号；sensitivity 子集含 episode 内真实除权，跨除权日的价格比较受机械除权影响，仅作对照。

## 首轮判读（裁决依据）

### 1. gap×λ（推进效率族）：NULL

主集 raw ρ=+0.040，控制后 +0.105，但股票 bootstrap 中位 −0.040，P05/P95 = [−0.250, +0.168] **跨零**。敏感集方向相反且同样跨零。结论：gap 与 λ 无稳定关联。**G2 FAIL。**

### 2. retention/touch 梯度：机械距离效应，非机制证据

retention 随 gap 单调升（0.26→0.48→0.97）、touch 单调降（0.85→0.71→0.14）几乎由构造决定：价格离锚越远，短期触锚概率当然越低。这是"距离到水平线"的算术，不是"事件成本有引力"。不能计为 G3 证据。

### 3. bounce|touch（回踩承接族）：无结构

主集三分位 40.5% / 31.9% / 52.9%——非单调、无梯度；且 t0（最贴近锚）反而低于 50%，即触及 AVWAP 后 5 日内更多情况停在下方，**不支持"事件成本线构成承接"**。样本内未见成本支撑结构。

### 4. drift10（重心迁移族）：测量无效，事后发现并声明

drift10 与 gap 的 ρ=0.79 / partial=0.998 是**构造性污染**：drift 分子含未来收盘价水平，gap 分子含当前收盘价水平，二者共享价格水平项，控制变量无法消除。该族在本轮操作化下**无效**，不计入任何 Gate；如需重启必须预注册趋势调整型漂移定义（相对前趋势的偏移），本轮不做。

### 裁决（按预注册停止条件）

- G1（构造有效性）：PASS（census）
- G2（独立性，λ 族）：**FAIL**（bootstrap 跨零）
- G3（行为一致性）：**未成立**（retention/touch 机械、bounce 无结构、drift 无效）

预注册停止条款："G2 失败即 CLOSE，不换锚、不调 band、不加核。"
