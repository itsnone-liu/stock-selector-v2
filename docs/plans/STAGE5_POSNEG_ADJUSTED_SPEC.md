## 2. 行情结局标签：顺序决策树（互斥）

以**复权价** `P_adj`、突破日收盘 `P_bo = P_adj(breakout_day)` 为基准、
观察窗 = 突破后第 1..20 交易日。回撤深度冻结为：

```
D = max(0, 1 − min(P_adj[1:20]) / P_bo)        # 始终上涨时 D=0（非取绝对值）
```

决策树（严格按序，首次命中即停，七类互斥）：

```
1. 右删失（outcome_20d_complete=FALSE）          → right_censored_undetermined
2. 窗内从未创新高（max(P_adj[1:20]) < P_bo）:
     2a. P_adj(end) <  P_bo×(1−θ3)              → breakout_failure
     2b. P_adj(end) >= P_bo×(1−θ3)              → breakout_unconfirmed
3. 窗内创新高，且 首个新高日 > 最低点日（先回调后新高）:
     3a. D <= θ1                                → direct_continue
     3b. θ1 < D <= θ2                           → shallow_pullback_new_high
     3c. D > θ2                                 → deep_pullback_recovery
4. 窗内创新高，且 首个新高日 < 最低点日（先新高后回调）:
     4a. P_adj(end) <  P_bo                     → fade_after_high
     4b. P_adj(end) >= P_bo                     → fade_after_high_recovered
```

- 分支 4b（曾创新高、深浅回调、期末收复但未再创新高）为 v3 新增第八类
  ——**裁定点E**：保留独立类（推荐，语义清晰）或并入 4a 统称 fade_after_high
- 新高标准：`P_adj >= P_bo`（与 v5 新高判定一致）；新高日/最低点日按
  **首个**新高日与**首个**最低点日比较；并列日（新高=最低点同日不可能，
  因新高≥P_bo>最低点，除非无回撤 D=0 且最低点=突破日——规定最低点日为
  `argmin`，D=0 时最低点日=首个新高日前一日或突破日，分支 3 生效）
- 门禁：非删失样本八类（或七类，按裁定E）恰居其一；分支覆盖率逐类披露

## 3. 策略比较口径（精确定义）

四种入场策略比较统一为三口径（v2 的 K1 条件成交收益由 K4 承接，不单列）：

| 口径 | 精确定义 |
|---|---|
| K2_h | **全生命周期策略收益**：每个生命周期都计入。已成交部分从**各自实际成交日起持有 h 日**；未成交生命周期的收益记 0（现金）。策略级 = 全部生命周期资金加权平均 |
| K3_h | **相同终点收益**：统一在**突破后第 h 日**估值。到该日仍未成交的资金保持现金（0）；已成交部分按该日复权持仓价值计 |
| K4_h | **条件成交诊断**：只看已成交事件，从各自成交日起持有 h 日 |

- h ∈ {1, 3, 5, 10, 20}，**三个口径在每个期限全部输出**（消除 v2 中 K4 只在
  5/10/20 与验收要求四口径齐全的矛盾）
- K2 与 K4 的区别 = 是否将未成交样本纳入（K4 无未成交样本）

**边界细则（冻结）**：
- 等待策略在共同终点（突破后第 h 日）**之后**才成交：K3_h 该窗口按未成交、
  现金 0 处理
- 恰在共同终点**当天**成交：计入交易费用，无价格收益
- 分批第三批在共同终点之后出现：对应 0.40 资金仍为现金
- 持有 h 日超出可用数据（右删失）：该口径该期限记删失，不进分母，删失率披露
- K2/K3 未投入现金收益按 0（裁定C 确认；不按无风险利率）
- staged_entry 全口径按组合净值（复权路径、30/30/40、逐批资金价值式）
- 3.5% 追入上限不动

## 5. 复权因子层（adjustment_v1）

### 5.1 因子语义

- 表存**累计总收益复权因子** `F_t`（后复权方向）：`P_adj_t = P_raw_t × F_t`；
  `R_{0,1} = (P_raw_1×F_1)/(P_raw_0×F_0) − 1`
- 现金分红按**再投资总收益**并入因子；送转股按股本变动并入
- 因子生效日 = 除权除息日（当日已用新因子）
- 默认值：无公司行动交易日因子延续前值（**不是缺失**）；新上市首日 F=1；
  停牌日沿用停牌前因子
- 严格缺失定义：按个股**真实行情日期**展开后仍有空洞（本地源公司行动表
  残缺、与行情日期不闭合）→ **fail-fast** 中止并报股票清单

### 5.2 因子源（先实证，不预设 gpcw）

1. 本地实证：盘点实际存在的公司行动文件，评估覆盖（股票数/行动类型/日期
   范围/闭合度），产出实证报告
2. 外部交叉验证：外部成熟前复权序列转换到同一因子语义后逐股对比
3. 以验证通过的源生成 `adjustment_v1`

**容差分级（按裁定修订）**：

| 层 | 容差 |
|---|---|
| 内部算法重复计算（同源两遍） | `1e-9`（比例） |
| 外部交叉验证 | **除权日必须逐股一致**；收益误差用与源精度匹配的容差（如 `1e-4` 量级，按供应商舍入/归一差异设定）；显示值仅分/厘精度时不要求 1e-9 |
| 人工公司行动样本 | 现金分红/送转/拆分后的**股数与价值守恒**逐一对照（≥30 只，覆盖三类行动） |

- 两源都不可靠的股票（裁定B）：开发阶段严格失败；正式分析若必须排除，
  须列出股票、原因、事件占比，并检查是否集中于特定板块或年份

### 5.3 净收益：资金价值式（取代"毛收益−成本占比"近似）

```
R_net = (复权后期末持仓价值 − 卖出费用) / (初始投入资金 + 买入费用) − 1
```

- 持仓价值按 `P_adj` 计算（含分红再投资与送转股数变化）；买卖费用按
  raw_price 资金口径（含单笔最低佣金）
- 分批策略**逐批**按上式计算，再加未投入现金，组合层面资金加权
- 门禁：人工公司行动样本验证分红/送转/拆分后的股数与价值守恒
