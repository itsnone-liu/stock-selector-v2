### 1.2 事前识别层（预测与识别，独立产出）

不与策略比较混合，输出为独立分析产物：

- **突破当日特征 → 形态归属预测**：以突破日及之前的信息（不含 t2/t3 之后任何
  行情）预测该生命周期落入 G1/G2/G3 的概率与判别特征。首版只输出单变量

- **回调当日 → 是否再上攻判断**：以回调事件内可得信息（缩量程度、回调深度、

- 硬边界：识别层结论**不得**反写信号准入或入场规则；只能进后续批次的条件研究。

## 2. 行情结局标签（独立于三形态）

三形态描述"入场机会结构"，不构成行情结局。结局标签以**复权价**、以
**breakout_day 收盘**为基准、观察窗 **20 个交易日**（右删失不判类）：

| 标签 | 开发级定义（预注册参数） |
|---|---|
| 直接延续 | 窗内 `max(P_adj)/P_adj(bo) - 1` 创新 高且最大回撤 `dd_max ≤ θ1`（3%） |
| 浅回调后创新高 | 创新 高 且 `θ1 < dd_max ≤ θ2`（10%） |
| 深回调后修复 | 创新 高 且 `dd_max > θ2` |
| 冲高回落 | 曾创新高但期末 `P_adj(end) < P_adj(bo)`（且未触发突破失败条件） |
| 突破失败 | 从未创新高 且 期末 `P_adj(end) < P_adj(bo)×(1-θ3)`（15%） |
| 突破未证实 | 从未创新高 且 期末在 `[P_adj(bo)×(1-θ3), P_adj(bo))` 区间 |
| 右删失未定 | 窗口不完整（`outcome_20d_complete=FALSE`），不进任何结局分母 |

- `dd_max` = 窗内 `min(P_adj)/P_adj(bo) - 1` 的绝对值（负值取绝对）
- 标签互斥完备：非删失样本七类恰居其一（门禁校验）
- **裁定点A**：θ1/θ2/θ3 的精确值（3%/10%/15% 为建议值）须在实现前冻结；
  不得据结果分布回调阈值
- 研究主问题"能扛住回调的股票有什么区别" = **形态 × 结局**交叉表
  （同为 G3，为何有的直接延续、有的再上攻后仍突破失败）

## 3. 策略比较：四口径并列

四种入场策略（direct_chase / wait_first_pullback / wait_support_hold / staged_entry）
不得只比成交样本——等待策略会主动放弃无回调直涨股。必须同表输出：

| 口径 | 定义 | 回答的问题 |
|---|---|---|
| K1 条件成交收益 | 仅成交行，自成交基准起（现有 v5 口径重算复权版） | 成交后买得好不好 |
| K2 全生命周期策略收益 | 每个生命周期都计：未成交资金按现金收益 0 计入（资金加权） | 整套入场政策好不好 |
| K3 相同终点收益 | 四策略统一至**突破后第 N 日**（N∈1/3/5/10/20）终点价，未成交=现金 0 | 同时点横比，市场区间可比 |
| K4 各自持有期收益 | 自各自成交日再持有 5/10/20 日 | 入场后的持有期表现 |

- K3 与 K4 **分列披露，禁止混合**（等待策略入场晚，混合即比较不同市场区间）
- K2/K3 的未成交=0 是**资金口径约定**（现金收益按 0，不按无风险利率），
  报告须注明
- staged_entry 的 K2/K3 按组合净值（复权路径、分批权重、窗口外出金为现金）
- 3.5% 追入上限在所有口径下不动（语义先于结果）

## 4. 前置 P0：复权因子层（adjustment_v1）

### 4.1 因子语义（补全定义）

- 表存**累计复权因子** `F_t`（后复权方向，无单位比例）：
  `P_adj_t = P_raw_t × F_t`；收益 `R_{0,1} = (P_raw_1×F_1)/(P_raw_0×F_0) - 1`
  （等价于因子比 × 价格比；方向选择只影响 F 的归一基准，不影响 R）
- **分红处理**：现金分红按再投资总收益口径并入因子（总收益复权）；
  送转股按股本变动并入
- **因子生效日**：公司行动的除权除息日（当日已用新因子）
- **默认值**：无公司行动的交易日，因子延续前值（**不是缺失**）；
  新上市首日 F=1 起点；停牌日沿用停牌前因子
- **缺失定义（严格）**：按个股**真实行情日期**展开后，若某交易日无因子记录
  且无法由前值延续规则覆盖（如本地源该股公司行动表残缺、与行情日起不闭合）
  → **fail-fast 中止**并报该股清单，不得静默跳过
- 数据快照：源文件字节数+内容哈希（SHA256）入 MANIFEST；因子表自身带
  run_spec_hash 与闭合校验（行数=Σ个股交易日数）

### 4.2 因子源（落地顺序，不预设 gpcw）

1. **本地实证先行**：盘点本地实际存在的公司行动数据文件（gpcw 或其他），
   评估覆盖（股票数、行动类型、日期范围、与行情日期闭合度），产出实证报告
2. **外部交叉验证**：取外部成熟**前复权序列**（akshare/baostock），转换到
   同一因子语义后与本地源逐股对比：因子比序列最大偏差、除权日对齐率；
   偏差超过 `1e-9`（比例）的股票进例外清单人工裁决
3. 以验证通过的源为准生成 `adjustment_v1`；两源都不可靠的股票 → 整股
   fail-fast 清单（**裁定点B**：是否允许"排除该股并披露占比"的降级模式，
   默认不允许）

### 4.3 统一改造（retcalc_v1 重算层）

- 收益/MFE/MAE/错失涨幅/结局标签/分批净值路径全部走 `P_adj`
- raw_price 保持信号/成交/涨跌停/滑点判定（STAGE4 §10b 双轴）
- 成本层（佣金/滑点）按 raw_price 资金口径计算，净收益 = 复权毛收益 − 成本占比
- 等价性门禁：无除权样本复权收益 == 现有 raw_price 收益（`abs=1e-9` 全量回归）；
  含除权样本 ≥30 只人工对照
- `return_quality`：`unadjusted_exploratory` 保持；新产物标 `adjusted_verified`

## 5. 统计口径

- **窗口**：1/3/5/10/20 日（v1 的 5/10/20 不够；1/3 日捕捉追高兑现压力）
- **主标签 = 行情路径**（§2 结局标签）；净收益正/负/中性作**并列结果**，不作唯一主标签
- **中性带（并列口径用）**：围绕 0 的毛收益带——净收益已扣成本，**禁止**再用
  "成本+滑点"作净收益中性带（重复扣减）；带的半宽=单边往返成本近似值，
  作用在**毛收益**上定义中性
- **不确定性**：股票块与日期块有放回 bootstrap 双套区间并列（大盘暴跌使同日
  多股同时失败，仅股票块低估共同冲击）；报告块数，表面行数不作独立样本数
- **T2→T3 间隔**：保存为**连续变量**（`t2_to_t3_days`，交易日），第一版不
  分箱；供后续研究，不进本批结论
- 分层最低要求：形态、结局、期限、视角；行业/大盘背景仅用于解释层，
  **不得**修改个股信号准入
- 删失：仅 `outcome_{h}d_complete=TRUE` 进对应期限分母；删失率逐格披露
