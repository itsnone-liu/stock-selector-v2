# E6：近期VWAP增量风险识别（2026-09-16）

## 口径

- 输入：E5 的13,616个股票-标签去重事件；事件日收盘后产生信号，次日开盘入场。
- VWAP：`sum(amount) / sum(volume) / 100`，TDX成交量按手转换为股；这是成交参考成本，不是持仓者真实成本。
- 固定分层：事件收盘价相对5/10/20日VWAP分别为 `<=-5%`、`[-5%,+5%]`、`>=+5%`。
- 主窗口：1/3日短线，30日中期；MAE/MFE分别观察3日和30日；10日不作主裁决。

## 首轮判断

1. 价格相对10/20日VWAP高出5%以上的事件，短线fwd1/fwd3和30日收益均较弱，MAE3/MAE30也明显更差；它更像“近期价格已显著脱离成交参考成本”的风险标签。
2. 20日VWAP下方超过5%的样本短线fwd1较好，但fwd3转弱，30日仍为负；不应把低于VWAP直接当作反转信号。
3. 5日极端组样本很少（21/339），只作观察，不作结论。
4. E6目前是增量风险识别实验，不改变生产候选、不自动拦截交易、不触发仓位调整。

## 限制

- 未复权股本/公司行动尚未完全纳入；
- VWAP单位转换已固定为100，但不同数据源单位仍需继续做量价合理性检查；
- 尚未做成本后组合回放、分块bootstrap和封存样本验证；
- 不将高于VWAP命名为获利盘或出货，只称价格-成交参考成本偏离。
