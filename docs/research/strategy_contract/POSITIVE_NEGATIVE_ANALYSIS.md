# 正负结果分析执行规范

## 主样本

以 `episode_panel` 的首次触发日为主，连续触发不重复计数。每日状态面板只用于状态演化描述。每个期限另可做按市场交易日的非重叠稳健性样本，不能把非重叠规则反写为交易冷却期。

## 七期限

1/2/3/5/10/15/20日分别计算，逐窗披露有效事件数、股票数、信号日期数。未成熟不进分母。

## 结果与路径

优先用行业相对收益按预注册噪声带分positive/neutral/negative，同时保留绝对收益和市场相对收益。价格路径分立即延续、延迟启动、冲高回落、直接失败、深回撤后修复。1日窗口不强求解释中长期路径。

## 分层

至少按：信号类型、阴转阳/双阳效率、星期路径、周线准入状态、事件时点行业、市场背景、半年。行业/市场字段缺失保持unknown。

## 不确定性

分别按股票块和日期块有放回bootstrap处理个股重复与共同市场冲击；这只改变置信区间，不修改信号逻辑。报告原始效应量、两套区间及块数，不把表面行数当独立样本数。

## 边界

脚本只消费冻结的signal/outcome/episode面板，不构造新信号。条件未闭合或同批数据用于调规则时，输出属于探索性分析，不能标作封存验证。
