# 资金动能体系边界契约

状态：第一批工程落地基准。本文只规定边界，不根据未完成回测裁决规则。

## 主通道

动态月线池（按事件时点可进入/退出） → 周线动能准入 → 日线买点 → 候选交易事件。

- 研究面板可在月线池内保留未通过周线或未触发日线的行，用于拆解，不等于这些行可交易。
- 明确负向周动能（如放量阴线 veto）不得进入主策略候选。
- bottom-volume 等专用通道单独建账，不混入主通道。

## 内外层

- 内层：个股月/周/日条件，回答资金是否仍推动个股价格。
- 外层：市场广度、指数风险、行业/ETF资金背景，回答整体仓位和行业暴露。
- 外层背景用于归因和仓位研究，不反写历史个股信号。

## 三版本

1. Legacy：忠实复刻旧源码；已知旧行为也保留。
2. Theory：按资金动能理论定义比较对象、折算与早周证据。
3. Optimized：只在 Theory 上做单因素改动。

三版本必须输出独立字段和 ruleset；禁止拼成一个“原版”。

## 研究期限

主期限为 1/2/3/5/10/15/20 个市场交易日；下一自然交易周单列。
30日仅用于历史结果对账。本轮条件未闭合、计算未验收前，收益结果不得用于否定或晋升策略。
