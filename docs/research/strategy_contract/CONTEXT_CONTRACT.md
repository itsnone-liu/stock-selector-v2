# 市场、行业与ETF背景关联契约

背景层只用于：结果归因、统计分层、外层仓位研究。它不修改历史个股月/周/日信号，也不因缺失背景删除个股事件。

## 关联规则

- 市场背景：按事件日 many-to-one 左连接；同日只能一行。
- 行业背景：按 `(事件日, 当时行业代码)` many-to-one 左连接；禁止用当前行业映射回填历史。
- 所有背景字段保留 source、observation_date、available_at；分析默认要求 `available_at <= 决策时点`。
- 当日盘后才可得的数据可用于“收盘后仓位决策”，不得冒充盘中可见。

## 口径

- 市场共同冲击：指数收益、涨跌广度、极端下跌占比等事实；股票/日期聚类只调整统计可信度，不改变信号。
- 行业背景：行业收益和广度优先；大单资金仅为代理，不能称为识别出的机构资金。
- ETF：总份额变化×NAV为新增ETF暴露规模，不等同二级市场现金买股；行业ETF和宽基ETF必须分开。
- 宏观/行业背景最终进入外层仓位研究，内层信号仍独立保留。

## 缺失行为

背景缺失=unknown。关联器左连接保留事件；报告披露每类背景覆盖率，禁止把缺失压成中性或零。
