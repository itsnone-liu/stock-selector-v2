# 动能理论—计算测量契约

> 状态：代码改造期冻结契约。正式回测须在P0–P4代码审计通过后另行执行。

## 研究目的

验证长期与短期资金行为的量价代理，对后续价格变化是否具有可重复的解释或预测信息：

```text
动态月线池（长期背景，允许进出）
  → 周线动能方向与效率（准入/观察/排除）
    → 日线动能与效率触发（买点候选）
      → 下一日、下一交易周及补充持有期结果
```

这是一项待验证的猜想，不是已证明规则。技术实现必须忠实测量原含义，不能根据阶段性收益反向改写理论。

## 含义—字段—判定—结果

| 理论层 | 主要量价证据 | 判定职责 | 直接结果窗口 |
|---|---|---|---|
| 月线 | 完整月、临时月、月线状态及池区间 | 动态研究总体，不直接替换周日条件 | 作为周、日研究背景 |
| 周线 | 周收盘对前周收盘、量额、效率、周内进度 | eligible / observation / excluded / unknown | 下一交易周；部分周另报本周剩余 |
| 日线 | 原版日线量价触发及连续证据 | trigger true / false / unknown | 下一交易日 |
| 背景 | 指数、行业、ETF、两融的PIT可见值 | 外层背景，不改写个股信号 | 事前条件与持有期冲击分开 |

补充滚动窗口冻结为1、2、3、5、10、15、20个交易日。下一交易周与滚动5日不得互相替代。

## 冻结边界

1. 涨跌方向比较采用当期收盘与前一期收盘；开盘只保留K线形态需要的含义。
2. `WeeklyEvidence.passed`保留Legacy语义，不因Theory分析而重定义。
3. 同进度与短周折算在未完成契约前只作为证据字段，不自动升级为新硬门槛。
4. 周一、周二保持已裁定方向：前两周动能正向时，不放量下跌可观察；下跌不套部分周上涨约束；上涨才检查滞涨。
5. 周二B反红、C缩量小跌保留observation；不得依据现有收益报告改为excluded。
6. 明确负向证据优先于通用unknown；门槛未满足与数据不足必须分开。
7. 市场、行业背景只用于归因与仓位研究，不改变个股月周日信号。
8. 统计去重、匹配、聚类和bootstrap只改变估计可信度，不回写选股逻辑。

## 三个必须分开的研究问题

1. **日线增量**：月线在池且周线eligible时，日线明确触发 vs 明确未触发。
2. **周线信息价值**：固定同一日线形态，eligible / observation / excluded分别比较，unknown独立披露。
3. **周线直接验证**：月线池内，周动能与效率对应下一交易周的表现，不以日线触发作为入样前提。

## 同结构分化目标

在相同月线状态×周线结构×日线形态内，对比正负结果的事前位置、累计涨幅、回撤、收盘位置、上影线、量价效率和PIT背景；再把持有期实际市场/行业冲击作为事后解释层。描述性收益分解不是因果归因。
