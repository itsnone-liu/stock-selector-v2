# 市场/行业基准及相对收益规范

## 日背景

从当日可交易股票横截面生成：市场收益中位数、上涨占比、跌幅≥3%占比和有效股票数；行业同样生成收益中位数、上涨占比和有效数。指数收益另作事实列，不能代替市场广度。

## 前视相对收益

对每个起点及期限h：

- `market_fwd_h`：同日起点全市场个股fwd_h中位数；
- `industry_fwd_h`：同日起点、事件时点行业成员fwd_h中位数；
- `market_excess_h = stock_fwd_h - market_fwd_h`；
- `industry_excess_h = stock_fwd_h - industry_fwd_h`。

行业成员按有效期PIT关联；重叠有效期报错，不静默选取。基准缺失保持NaN且不删除事件。基准宇宙、停牌、上市天数与可交易性过滤必须在正式运行manifest中记录。

相对收益用于回答共同冲击与个股增量，不能替代实际绝对盈亏和可执行收益。
