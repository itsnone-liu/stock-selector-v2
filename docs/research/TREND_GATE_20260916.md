# 周趋势门槛裁决实验（2026-09-16，800只/2022-01→2026-09）

问题：weekly_trend 硬门槛是领先信息、同步信息，还是滞后的多余确认？
候选集 = 月线通过 ∧ 周级动能 active_up ∧ 日线标签命中 ∧ regime∈{bull,mid}
（即 feature_only 口径买点全集；hard_gate 是其中 trend≠none 的子集）。
入场=次日开盘；PIT（尾部550根切片 + regime按日共享）。

## 读法

1. **硬门槛没有过滤价值**：被排除的 none 组（占候选 55%）fwd10 中位 -0.05%，
   不比留下的 ma_bull 组（-0.34%）差。A(hard_gate) ⊂ B(feature_only) 的收益
   差异整体为零——"趋势越多越安全"不成立。
2. **ma_bull 是滞后的多余确认**：8 个半年里只有 2025H2 为正（依赖牛市段）；
   mean>median 为正全靠右尾，中位数为负。
3. **macd_stabilizing（金叉企稳）是唯一有跨期一致性的组**：5/8 半年为正，
   含 2023H1 弱市 +1.6%、2026H2 近期 +1.3%；牛市 +1.17% / 中位市 +0.16% 双正；
   MAE 最小（-2.92%）。周趋势的信息不在"确认趋势"而在"早期企稳"。
   ——与底部三倍量池方案（跳过月线多头→周线小金叉路径）互相印证。
4. **绝对收益都小**：全部组 fwd10 中位 ≤ +1%，none/ma_bull 组接近零——
   与滚动验证 R3（标签无样本外超额）一致：买点复合体仍无强 alpha，
   stabilizing 是"残差里最值得追的线索"而非可晋升结论。

## 追加：stabilizing 组细分（同日切片）

**stabilizing × 日线标签（三种标签全正！）**：

| label | n | fwd10中位 | 均值 |
|---|---|---|---|
| pullback_holds | 450 | +0.92% | +0.60% |
| shrinking_volume_acceleration | 125 | +1.28% | +1.78% |
| two_day_acceleration | 240 | +1.04% | +1.36% |

对照：同标签在 ma_bull/none 组内全部 ≈0 或负。**stabilizing 是抬升全部
买点的"语境"而非某标签专属效应**——买点的有效性取决于周线早期企稳语境，
不取决于买点本身。这与"先确认大方向，再观察资金何时推动"一致。

**stabilizing × 星期**：周一中位 0.00%，周二~周五 +1.0%~+1.6%——周一
（证据最不完整日）事件显著更弱，与 legacy 周一逻辑（只看完整周）方向一致。

**标签构成差异**：stabilizing/none 组以 pullback_holds 为主（55-57%），
macd_cross 组加速类标签更多（42%+42%）——组间差异不能全归标签构成。

## 第三轮：月线门槛 × 周趋势交叉（79,314 候选，含月线未通过宇宙）

fwd10 中位（n）：

| | ma_bull | macd_cross | macd_stabilizing | none |
|---|---|---|---|---|
| 月线通过 | -0.34% (7,477) | 0.00% (507) | **+1.00% (815)** | -0.05% (10,556) |
| 月线未通过 | -0.31% (13,204) | -0.21% (3,328) | **+0.56% (3,233)** | 0.00% (39,772) |

**结论：**

1. **月线多头不是 alpha 源**：none/ma_bull 组在月线通过与否两侧几乎无差
   （-0.05% vs 0.00%；-0.34% vs -0.31%）。月线是风险语境不是收益过滤器。
2. **stabilizing 语境在底部宇宙里也活着**：月线未通过 × stabilizing = +0.56%，
   且 MAE 全表最小（-2.50%）——企稳信息不依赖月线多头背景，真实。
3. **但底部池版本强度约减半且更脆**：+0.56% vs +1.00%；半年正收益率 6/10
   （对照通过组 5/8），2026H2（近期弱市）转负 -1.5%（通过组仍 +1.3%）；
   regime 切片牛市 +0.48% / 中位市 -0.08%——底部池通道是**牛市依赖的更弱半边**。
4. macd_cross 两侧都无期望值，"小金叉"里只有 stabilizing 一半携带信息。

**对底部池方案的裁决**：信号真实但弱（约为月线内 stabilizing 的一半强度），
适合作为专用小仓位通道（跳月线→仅 stabilizing→小仓位+更严退出），不适合
作为主通道替代。2026H2 转负提示弱市里底部企稳的失败率上升，与"弱市专用
规则需另行设计"的既有判断一致。
