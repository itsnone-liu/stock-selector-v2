# 周趋势门槛裁决实验（2026-09-16，800只/2022-01→2026-09）

问题：weekly_trend 硬门槛是领先信息、同步信息，还是滞后的多余确认？
候选集 = 月线通过 ∧ 周级动能 active_up ∧ 日线标签命中 ∧ regime∈{bull,mid}
（即 feature_only 口径买点全集；hard_gate 是其中 trend≠none 的子集）。
入场=次日开盘；PIT（尾部550根切片 + regime按日共享）。

## 读法

1. **硬门槛没有过滤价值**：被排除的 none 组（占候选 55%）fwd10 中位 -0.05%，
   不比留下的 ma_bull 组（-0.34%）差。A(hard_gate) ⊂ B(feature_only) 的收益
   差异整体为零——"趋势越多越安全"不成立。
2. **ma_bull 是滞后的多余确认**：8 个半年里只有 2025H2 为正（依赖牛市段）；
   mean>median 为正全靠右尾，中位数为负。
3. **macd_stabilizing（金叉企稳）是唯一有跨期一致性的组**：5/8 半年为正，
   含 2023H1 弱市 +1.6%、2026H2 近期 +1.3%；牛市 +1.17% / 中位市 +0.16% 双正；
   MAE 最小（-2.92%）。周趋势的信息不在"确认趋势"而在"早期企稳"。
   ——与底部三倍量池方案（跳过月线多头→周线小金叉路径）互相印证。
4. **绝对收益都小**：全部组 fwd10 中位 ≤ +1%，none/ma_bull 组接近零——
   与滚动验证 R3（标签无样本外超额）一致：买点复合体仍无强 alpha，
   stabilizing 是"残差里最值得追的线索"而非可晋升结论。

## 已知偏差（不削弱内部对比，削弱绝对水平）

- 幸存者：样本按今日流动性合格回推；
- 事件重叠：fwd10 窗口重叠，n 夸大（中位数稳健但非独立样本数）；
- 无成本；2022H2 起（2022-01 起点）。
