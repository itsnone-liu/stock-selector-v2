# CF-IS Phase 2B 后续比较边界

本页固定下一步的研究问题，不据当前结果改A/B/C规则。

## 当前可检验与不可检验

- 当前可复核六轮episode从A到失效/到期的状态事实，不能以12周末正收益将中途已失效的候选改称有效。
- 当前可检查全部可评估周的后验4周反弹标签是否落在已有episode内；这些不是独立底部样本，不能拿标签周数作大样本显著性。
- 当前不能完整验证宏观是否关键：事件目的选样且背景日序列未接入，宏观关联缺失不等无宏观冲击。
- 国家队/大资金/主力游资/散户身份数据仍不齐；ETF、融资、参与和广度仅是不同机制的行为代理，不能把它们直接命名成四层真实资金流。

## 下一步优先级（先补证据，后谈规则）

1. 日历：接入明确来源、含版本与日期范围的交易日历，区分春节长休与真正缺失，原先保守断档结果不静默改写；并列旧口径与新口径差异清单。
2. 宏观连续背景：先核对可用的美元/美债/人民币/油价历史序列和各自发布时间；历史新版复权/修订不得伪装当时可见。当前只做来源库存，不假定有可用序列。
3. 反例：对失败A、等待B/C以及无A的反弹期展示事前条件，不用事后“没有支持”替代原始数据。
4. 比较：先覆盖度与逐episode对照，未触发时期也保存；只有对照与数据覆盖足够后才考虑固定规则与纯价格背景的增量比较。不因6轮样本不足合并状态/放宽阈值。
5. 前瞻：暂不输出当前市场路径概率。若以后做预测，概率需要校准与明确的预测时点，不能用六轮目的样本生成精确百分比。

这是Phase2B内研究，不启动Phase3、生产交易、仓位优化或关闭模块重开。

## 本轮诊断后的暂定判断

六轮中4轮LOSS、2轮到期。194个当时已知周中179个有完整四周结果，33个达到固定的期末+5%后验标签（合并相邻为13个run，仍非独立事件）；其中30个标签周当时无活跃episode，3个在已有episode内。实际6个A起点没有一个在四周期末达到+5%，但这不等于6轮都是失败或更长期均无收益。

这些结果目前反对将A v1当通用底部入口。其融资收缩缓和条件只覆盖一种去杠杆修复路径，深回撤条件也天然排除较浅回调和趋势延续。后续即便构建其他路径也应独立命名、先定义再验证，不能悄悄放宽原A并沿用原验证结论。

本轮未将4/8/12周固定持有结果当交易验证。无活跃episode也不等于真实交易错过全部涨幅；需要共同时间轴与费用/退出模型才讨论机会代价，当前只指出覆盖问题。
