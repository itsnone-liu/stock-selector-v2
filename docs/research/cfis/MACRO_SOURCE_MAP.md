# CF-IS 宏观来源图谱与事件扩充

## 分层

1. 国内：人民银行/财政部/统计局/国务院/证监会，保留原发布日与生效日。
2. 联储：Federal Reserve FOMC 声明、实施说明、发布会、纪要；FRED/ALFRED 可补背景与历史 vintage，但不把最新修订序列当当时已知。利率维持也收录，不能仅选加降息。未取得当时预期则 surprise 留空。
3. 贸易：USTR、Federal Register、美国商务部 BIS、中国商务部与关税税则委员会。区分宣布/提案/终案/生效/豁免/延期/反制/缓和；原文失效URL不算已核实来源。
4. 地缘：联合国与各方公开声明；Reuters/AP等辅助交叉确认。明确声明事实与战场事实，单方说法不能升级为独立核实。战争、停火、航运/能源中断分开；不泛称所有中东事件为美伊直接战争。

## 时间与证据

- 保存原时区；转中国时间后再映射观察周，不能把美国周三下午公告放进中国周三盘前。
- first_usable_at 是公开信息可用时间或明确标记的保守上界，不代表可成交时点；中国交易日/休市日映射尚未实现，不伪装精确开盘。
- effective_at 的含义必须明确：种子中部分沿用公告发生日期，不等于政策实际执行或统一生效日期；其 semantics 字段与 timing_note 是解释依据。
- 事件后美元、美债、汇率、油价的变化是反应变量，不能倒用为事件发生时已知强度；后续若用于确认，只能在其可见时点升级。
- 事件簇去重不等于独立样本：联储降息与国内政策窗口可重叠，同一战争/谈判过程也存在强依赖。
- 本次仅核实有限事件事实，不预测不可知的政策或战争日期；最终要检验事件前结构与事件后接力的条件关联。

## 纳入标准与当前缺口

首轮采用有可访问正文、可确认日期的有限事件种子，不以事后股市正负收益标利好/利空；仍属已知历史目的选样，不能宣称无偏。当前尚未实现完整FOMC日历、完整关税变更普查、地缘事件独立交叉核实、预期差、宏观连续背景序列及行业暴露表。它们均不能由事件标题替代。
