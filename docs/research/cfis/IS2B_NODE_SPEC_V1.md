# CF-IS A/B/C 候选节点 v1（首轮固定规则）

规则先写后跑，不做参数扫描；已看过历史，属于探索不是预注册/OOS。先只验证市场参与时机候选，非个股买点。大资金层披露不齐与宏观背景尚未完整纳入，不称四层模型。

## 可见特征

既有000985 OHLC价格序列按周组织，必须周末端点存在；相邻日差>14天视为断档，连续8/12个观测交易周的历史窗口不得跨断档。自然休市周不制造样本。历史价格至该周末为止，周表 usable_at非空且availability_unknown=0，评估时点用该周usable_at。原子/价格版本无历史vintage，称保守可见代理，不宣称真正可交易PIT。

- dd12：当前周收盘/最近12个可用交易周最高收盘-1；只作压力背景。
- low_change：本周最低/前周最低-1。
- downside_pressure：周内负日收益绝对值之和；不是实际卖单/强平金额。
- pressure_easing：最近2周下行压力均值<=此前2周均值，且此前均值>0。
- margin_easing：最近2周融资净变化均值>=此前2周均值；并要求此前2周均值<0。
- coverage：所用历史周的指数日数据/周表输入与时间字段齐备；不跳过坏周构造连续窗口。

## A/B/C 首轮规则

A 早期平衡候选：dd12<=-5%；本周low_change>=-1%；pressure_easing且margin_easing；最近2周l1_fam_delta_w均值>=0（支持代理未收缩）。

A触发新episode后，追踪最多12个交易周：
- B接力启动候选：首次breadth>=0.50且part>=1.0且本周指数周收益>0（不要求融资转正，避免错过低杠杆修复）。
- C修复确认候选：B后更晚一周起，连续2周breadth>=0.50，且本周指数收盘高于A时收盘。
- 失效：某周收盘<A周最低价×0.97，优先失效，不在同周升级；或12周到期。重叠A合并为一个episode；不允许同周跨A/B/C，等待期内不建第二episode。A后下周才可失效/升级。
- A以外未满足是无候选，不是“市场不可能见底”。阈值只给一版，不为样本不足放宽到有结果。

## 结果单独计算

对每个A/B/C的assessment时点，选择严格晚于该时点的首个有记录指数交易日开盘作为entry_proxy（遇>7自然日仍无数据视缺口不评估，不跨历史断档）。这只是可执行时间顺序代理，不含滑点/费用或开盘成交保证。

4/8/12个后续交易周：从进入周开始算；需每周至周五或可确认休市前最后记录日端点齐备，当前周必须整体处于assessment之后。不能不足期补零。跨异常日断档或任何所需基准周缺失则结果空/删失。逐日low计算MAE、high计算MFE；terminal_return用完整窗口最后close/entryopen-1。等待到首次close>=entryopen×1.05的交易日数，同时记录是否未达（删失），不得以窗口结束天数当达标等待。

宏观事件关联仅列first_usable_at<=assessment的最近过去28天已公开事件，不将将来事件或之后行情写入节点；未来事件可在结果解释中另列，不能作触发依据。节点表与结果表分开，episode数而非行数作样本量。无显著性/概率声明，无策略收益或生产接入。

## 结果时间精度补充

本地指数末日2026-04-30（周四）没有后续记录，不能单凭weekly week_end也是4/30就认定完整周；无官方日历时，结果程序仅对周五端点或有后续周记录佐证的历史短周计完整。末尾非周五按右删失处理，不倒填未来交易日。

MAE包含零基准（min(0,相对最低价变化)），MFE同理max(0,..)；等待+5%按首个评估后进入交易日=1。完整窗口未达标只标未达到/等待右删失，不用窗口长度伪装达标时间。不同阶段无法到达是状态机选择，不当作零收益。
