# 成交扩张过程首轮判断

基于同一条TDX统计成交额代理与既有市场广度/等权日收益代理，非官方资金净流统计，非新买点验证。

1. 用户提出的参与规模跃迁有数据痕迹：2024年8月日均约5972亿元，10月约20145亿元、11月约19676亿元；不是只有9/30或10/8一个尖峰。10月/8月约3.37倍，量能中心有明显抬升。
2. 2024年9至11月金额与广度/价格推进同时改善：9/10/11月日上涨广度均值约.553/.536/.526，等权日收益复利约+23.72%/+6.86%/+4.93%。这是参与扩张与广泛推进一致的描述，不能证明净资金进入造成上涨。
3. 12月日均仍约16111亿元，但广度均值降至.466、等权代理约-4.21%；2025年1月日均进一步降至约12055亿元。这提示初段扩张后存在收缩与分化，不是长期始终同强度普涨。
4. 2025年8/9月日均再次约23078/24172亿元；8月广度约.536而9月约.459。相近/更高成交额可能对应不同扩散状态，高额本身不是持续上涨信号。
5. 既有周表中2024-W39融资净变化转为约+232亿元、W41约+1405亿元；这是杠杆参与变化，不是证明全部接力资金身份。ETF支持代理后来下降而某些周广度仍改善，可以作为“支持与扩散不必同步”的待验案例，不能宣称国家队已出货。

**方向判断：用户提出的研究对象比旧A更贴近实际可参与过程，值得继续。当前支持的是“2024年秋出现持续参与规模扩张且初段伴随广泛推进”，而不是“高成交额必然开启牛市”或“扩散入口已经验证提高胜率”。**

下一步要验证的是扩张后可参与阶段的风险/空间与持续性，不是从历史最小额到最大额挑漂亮倍数。独立扩散入口不要求旧A；至少同时保留高额但弱广度/负推进的反例，测试调整后再推进，而非单次脉冲。较长周期与个股分布尚待完整价格覆盖和复权/股票历史集合核验。
