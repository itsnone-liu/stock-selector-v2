# CF-IS 独立扩散与对照 v1（先固定后计算）

探索性：已看2024过程，不是预注册或样本外。只测一版规则，不参数扫描；不依赖A，不改旧A。市场级价格路径，非策略收益/个股买点。宏观不作入口。

## 每周可见描述

以冻结weekly_full各周为观察架构。最后10个TDX观测日须覆盖当周末，日金额/过去60日均值ratio60皆有效，相邻日期不得>14天；该10日中至少7日ratio60>=1.2定义AMOUNT。不能用当月事后均额。TDX当日可用假设次日00与周表usable_at取较晚者，周表unknown则未知；当前与前一观测周须有效且数据时间均<=assessment。

BREADTH：当前与前一观测周ax_breadth均>=0.50。PRICE：独立000985当前周末close>此前4个观测周最高周末close；五个周末都存在，相邻真实日期不得>14天，不能跳过缺失周。这里只定义简单价格突破，不宣称最佳纯价格策略。

四组同一共同可评估周（AMOUNT/BREADTH/PRICE皆已知）：
- DIFFUSION = AMOUNT AND BREADTH AND PRICE。
- AMOUNT_ONLY = AMOUNT（忽略另外条件，不是排除它们）。
- PRICE_ONLY = PRICE（忽略另外条件，不是排除它们）。
- ALL_ELIGIBLE = 每个共同可评估周；只作市场机会背景，不为独立episode臂。

各信号臂单独合并连续触发周为episode，仅首周为entry；相邻观测周若未知必须打断，不能让后知信息补历史。不同臂共享样本，不能当随机/独立对照。同一臂再次触发可产生新episode，但结果窗口仍会重叠，报原始数量与时期集中。ALL_ELIGIBLE结果逐周仅背景，不拿周数当大N检验。

## 独立长周期结果

assessment之后首记录09:30开盘为进入代理；>7自然日无记录或跨>14日原始指数断档不评估。month horizon=3/6/12自然月，从entry日期加相应月、月末截日规则；取目标日当日或之前最后实际日close，目标日不得超过原始价格末日，且尾端离目标>7自然日视缺口。端点只用既有实际数据，不用未来补齐。

逐日路径要求与TDX市场观测日期在entry..end完全对齐（TDX不是官方日历，仍标源一致性而非官方全覆盖），相邻price日>14天保守缺口；春节等真休市可能被拒，保留未放行不悄悄用新日历。return=endclose/entryopen-1；MAE=min(0,minlow/entryopen-1)；MFE=max(0,maxhigh/entryopen-1)；首次close>=entryopen*1.10交易日，未达标不填成功等待。

未来结果只入outcome。原index止2026-04-30，后期入口及12月窗大量右删失必须逐项报，不以短窗冒充长窗。主要列逐episode和中位数/范围（若数量不足不报胜率）。旧A另列但不混成同期随机臂；先做描述，不输出显著性/概率或最优买点判断。
