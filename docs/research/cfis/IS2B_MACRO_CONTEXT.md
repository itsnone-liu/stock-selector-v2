# CF-IS 连续宏观背景首批：美元隔夜利率

## 实际接入

纽约联储官方Markets API获取SOFR（1101条）、EFFR（1107条），范围2021-12-01至2026-04-30。原始JSON保存data/cfis/macro_raw（ignored），source URL、条数、SHA256见is2b_macro_manifest.json。程序默认离线读取快照，显式`--fetch`才联网重取。周表194个current_known周逐周连接；不改变候选/结果文件。

- SOFR是美国国债担保隔夜融资利率，并非A股融资成本或全球流动性总量。
- EFFR为有效联邦基金利率，不是联储目标区间或市场预期路径。
- 两者利差只有相同effectiveDate才计算，不拿不同日的数据相减。
- 官方说明：https://www.newyorkfed.org/markets/reference-rates/sofr 实际正文指出每工作日约08:00 ET公布SOFR。API effectiveDate是利率所属日期，不是公告时间。

## 时间与版本限制（重要）

本批API是当前历史版本，不是历史发布快照。修订标记原文保留于raw，仍不能恢复每次历史修订。不得宣称真正PIT。

输出统一标LATEST_VINTAGE_NOT_PIT。连接采用**所属日+7自然日**保守研究假设，最多14自然日陈旧；该假设不是官方首发时间，不能抹去版本泄漏风险。28日变化以前28日评估时点可选值比较，不把未来值回填。缺失/过期留空，不能沿用无限期旧值。

## 未接入及失败记录

- FRED DGS10 graph CSV多次返回HTTP文本错误页而非CSV，未作为数据入库。
- 美国财政部yield XML本次连接超时，未捏造或用搜索摘要补值。
- ECB eurofxref-hist.csv返回的内容含2010-02-14及整齐测试数字，与目标历史汇率内容不符；拒绝入库，不能因URL官方就信任异常响应。
- 美元指数、美债长端、人民币和油价本批仍缺，不能以SOFR/EFFR两个高度相关序列冒充完整宏观四轴；不做综合天气分或因果验证。

## 复现

`python3 scripts/cfis/is2b_macro_context.py`；若本机无raw快照，先明确联网使用`--fetch`。输出data/cfis/is2b_macro_context.csv；重取可能改当前历史版本，需重新核对manifest，而不是覆盖后继续引用旧结果。
