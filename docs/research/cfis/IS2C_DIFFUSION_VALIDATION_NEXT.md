# 扩散参与验证下一步：固定问题而非追求最早买点

本轮先核对成交额跃迁，未输出新交易信号。下一批依据完整历史覆盖，先固定独立扩散描述与对照，再看结果。

## 必须回答

1. 相对此前60日的成交参与抬升，是否超出一个短脉冲并在多周维持？金额增加是范围扩大还是少数方向高换手？
2. 广度、行业覆盖是否同步改善，收益由少数权重还是广泛股票贡献？正贡献集中指标仅做已有口径，不冒充成交额集中。
3. 首次推进后的回落，成交与下行冲击是否缓和，低点与参与是否仍有支撑？再次扩散是否发生？
4. 在扩散已出现后进入，与早期A、只按价格回升进入相比，未来3/6/12个月的风险/空间/等待/覆盖如何？阶段入口不要求先A，不能拿未来扩散长度倒定当时入口。
5. 哪些高额时期没有普涨甚至下跌？这些反例必须和2024-09过程同时纳入，不能把成交额高全部解释为新增承接。

## 指标语义分离

- 成交额/过去基准：参与规模痕迹（成交不是净流入）。
- ETF份额、融资：入口与杠杆变化痕迹，非所有投资者分类真实净流。
- breadth：当日上涨股票比例，月均不等于月内上涨股票占比。
- eq_ret复利：横截面等权日收益代理，不是固定股票组合净值；不能用它计算所有个股从924以来最大涨幅。
- conc50：正收益×成交量贡献集中度，非资金流向或成交额前50占比。
- 月均额只是描述，不可把整月统计回到月初作为信号；日级trailing20/60排除当日用于基准，完整月后才能比较月结果。

## 数据与比较次序

当前指数价仅到2026-04-30；欲评价近两年资金与价格过程，应先补价格及确认覆盖，不用金额尾部代替缺失价格。个股长周期需处理退市/上市/复权与期间涨幅分布，不能用今天存续股票集合回填。

原A/B/C与所有反例留为旧路径基线；扩散不是救A，而是用户明确的不同参与路径。本轮研究仍为CF-IS探索，非R6-2机制授权；不综合评分、不推交易指令。
