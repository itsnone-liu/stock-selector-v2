# IS2B 反弹覆盖诊断（非规则修改）

目的：不只看已触发A；以固定前瞻4周市场上涨>=5%的历史周为后验诊断样本，检查当时为何没有A。该标签只进coverage结果，不回写特征或节点。所有合格周保留，不能只列著名底部。

- 评估范围：原features所有current_known=true的周，使用原结果评估器的严格assessment后进入、4完整交易周规则；任何缺口/右删失保留状态，不归“未涨”。
- 4周期末return>=5%定义为诊断中的rally标签，非底部/成功交易的定义。报告所有有效周上涨率只是描述，不声称规则召回率/胜率。
- 按当周是否实际A、A条件满足但已有episode而合并、特征不全、完整但至少一项A条件不满足分栏。不同stage的已有episode可以覆盖未来行情，不能把没有新A就称完全错过。
- 失败条件分别列dd12不深、低点仍下移、下行压力未缓和、融资收缩未缓和、支持均值负值；多条件同时记，不强分单一归因。不完整指标不归False。
- 相邻rally标签往往共享未来结果，不是独立样本；使用所有标签周与按标签周相邻观测序号合并的run数并报，run只是相关性展示，不是经验证独立事件。
- 只有当时已知行可作起点，不把缺数期当规则拒绝。不调整阈值扩大覆盖，不据已看结果重命名A为成功节点。
