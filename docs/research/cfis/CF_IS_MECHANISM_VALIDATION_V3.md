# CF-IS 验证方案 v3：逐利、供需与获利机会的集中/扩散

> 用户最新修订为上位方向；本页取代v2及IS2C中“从量价门槛寻找有效买点”的主线。旧产物保留为描述底稿与反例，不当机制验证。此为方案修订，不启动新一轮信号回测、不重开关闭模块/R6-2。

## 1. 两个出发点与必要限定

1. 逐利资本在可选资产中寻找可实现的获利路径。承接须解释谁愿意买、准备由何种价值/需求变化获利、如何具备兑现条件。意图不等于结果，资金会误判和亏损；不假定“主力不能亏所以必拉”。政策、被动、配置资金目标另列，不能套统一短期逐利目标。
2. 价格由边际买卖意愿及可成交供需决定。卖压减少且买方未同步枯竭，供需改善；买方枯竭而卖方仍在，供需恶化。缩量本身不区分二者；卖出股票总有买方，不用“买入总额大于卖出总额”叙述净流入。出清指特定价格附近急于卖出的压力减弱，非所有人卖光；涨价后会产生新供给。

验证顺序：**事前资金假说→可区分行为痕迹→来源与覆盖→按当时信息复原过程→竞争解释与反证→最后检查参与价值**。收益/统计工具只能核对后果，不能以回归显著、胜率或量价相关代替上述因果链。

## 2. 资金获利链六问准入

- Q1 服务判断：区分获利机会集中、广泛接力、需求退潮；之后才讨论参与范围/方式。
- Q2 链上环节：资金选择方向→吸收局部供给→推进形成浮盈→吸引接力→具备兑现条件。
- Q3 可观察痕迹：同期机会宽窄、参与集中/迁移、回落卖压与承接、不同进入批次的获利余地及成交约束；主体证据有则单列。
- Q4 收益差机制：有限逐利参与若集中在可吸收供给的少数方向，局部需求可超过当地出售意愿；广泛接力则使更多资产形成相同推进条件。失效于供给增加或后续需求不足。须区分消息驱动、基本面重估和成交不可执行等竞争解释。
- Q5 如何证伪：见各路径反证，不用事后故事救结果。
- Q6 新增什么：解释“为什么有限机会时集中、为什么机会扩散时更多资金愿意接”，而非替换已有关联量/动量/成本模块。既有指标仅L2痕迹，不凭改名晋升机制量。

## 3. 路径C：广泛机会不足下的局部集中（抱团/俗称妖股期）

### 核心待验链

广泛方向难以形成可实现收益、市场级购买力/承接不足 → 仍愿承担风险的活跃资本寻找局部可推进对象 → 参与与注意力集中 → 局部供给被吸收，价格推进形成盈利反馈 → 跟随需求继续集中。

用户判断“熊市妖股多”作为重点假说，不先写成事实。存量/增量资金难以直接识别；成交集中不是存量身份的证明，“只能抱团”先解释为其他可行获利方向较少，不排除空仓、债券或退出市场。

### 三个独立命题

C1 熊市极端强势对象**绝对数量**是否更多；C2 在全部活跃对象/有效股票中**占比**是否更高；C3 盈利机会和交易参与是否更集中。C2/C3成立不等于C1成立；市场弱时赢家稀少会自然提高显眼程度，不能混作妖股更多。

### 不用未来挑妖股

不用事后最高涨幅、后来连板长度或最终崩盘日选样。第一批称“局部持续强势/集中推进对象”，先在当日识别前段形成，截断以后数据再观察继续/消散；不等同普通高RS或已验证选股入口。俗称妖股只作解释词，正式可操作定义须等数据库存完成后单独固定，不因著名案例能入选而调整。

广泛机会不足的背景先独立判读，不包含“有妖股”本身；保留市场普遍下跌、震荡低参与、上涨但分化等不同背景。首轮描述用已有市场价格/广度，后续核对同月/前月滚动可实现机会、亏损面与资产范围，不能将未来亏损作为当时背景。

### 必须核对的顺序与竞争解释

|环节|期待看到的痕迹|不能据此直接声称|关键竞争解释/反证|
|---|---|---|---|
|广泛机会收缩|多数可选方向先弱，活跃机会范围变窄|所有资金无处可去|集中现象先于市场弱，或市场强时同样出现|
|参与集中|少数当时已识别对象的成交/换手/同类参与迁移|同一游资持仓搬家|指数权重、单一行业重大消息、涨停制度改变|
|局部吸收/推进|遭遇抛售仍有成交承接、回落冲击减轻，随后有更高价格交易|有人控盘、真实主力成本已知|一字板/停牌导致不可买，低流动性报价幻象|
|盈利反馈/接力|形成后新进入批次仍存在可成交获利余地，参与者范围扩展|后来资金必赚钱、真实持有人已兑现|仅最早一批有浮盈，后进入者持续受损|

只见极端上涨而没有前面的供需与集中顺序，只能叫强势现象，不称“机会匮乏导致抱团”获支持。真实主体/持仓缺失降低结论等级，不用龙虎榜叙事或融资代理补身份。

**形成与崩塌分批研究**：本批先回答为什么集中出现及如何形成，不要求先做顶/崩盘预测；可在形成链中记录需求中断反例，但不把退潮时机模型混入立项。

## 4. 路径D：参与扩张后的广泛接力

核心链：部分资产先出现供需改善与盈利→更广泛资本愿意进入其他仍具获利空间的方向→供给在更广范围被吸收→新参与批次也获得推进→调整时卖方释放未破坏承接→再推进。

2024-09的5000亿附近到20000亿以上，只是参与规模变化的起点证据；必须核对资金入口、获利机会扩展、资产间迁移及回落承接，不能4倍成交额等同4倍新增资金。

逐日/逐周顺序复原，不再要求成交、广度、价格同周一起达标；不先设“扩张后N周内必须新高”来凑命中。先标各证据实际发生时点，说明先后/并存/缺失，再决定是否存在可复用的过程结构。

竞争解释：政策脉冲、普通超跌、高额换手兑现、指数上涨但多数方向无法获利。对照必须包括高额弱推进、低额仍推进、扩张后中断、无明显扩张仍修复，不只2024年秋。

## 5. 不能把结果重新包装成解释

- 价格上涨不是独立的“卖方出清”证据；“后来涨所以当时有承接”属循环论证。
- 平均获利不等于每个进入者获利。以历史可见价格/成交约束构造进入批次代理，分开浮盈、可成交退出和真实兑现（通常未知）；不称“主力成本/实际利润”。
- 推进效率描述不能自动成为独立机制：较小成交对应较大涨幅可能是流动性薄弱，也可能是供给减轻，必须看受抛售时反应及价格可成交性。
- 单看市场反弹数目、持续高额或后续收益，不足以说明资金逐利路径已闭环。
- 回归/概率不作为本轮主产品；若以后用统计工具，其用途仅为检查某解释是否稳定、是否明显与反例冲突，不替代机制。无需为“不确定主体是谁”停止判断，但必须明示观测/推断/未知。

## 6. 具体实施批次与停止线

### V3-0 数据与过程定义（下一批，先不算策略收益）

逐项盘点已有个股日频amount/volume、复权价格、流通盘、涨跌停/停牌、历史上市退市集合、板块映射的时点语义。市场TDX880005只是聚合额，不能回答流向哪些对象；缺口如实列，不为完整而造流。

交付：来源与单位表；候选形成对象的当时可识别定义草案；熊市/机会不足背景的独立定义草案；典型与反例的固定取样规则。先盘点后冻结可操作定义，不在已看结果后挑阈值。

### V3-1 形成过程账本

保留全部符合定义的形成/未形成对象，而非名单挑明星。形成、吸收、推进、接力各条证据记日期、原值、来源、当时可见性和竞争解释。每一步标OBSERVED/INFERRED/UNKNOWN/CONTRADICTED。同一行情不重复记独立证据；少样本逐例说清，不能凭周数制造大N。

先做熊市、低参与震荡、广泛上涨、上涨分化四类背景的对照；市场背景不改变原个股信号，研究旁路不覆盖生产逻辑。

### V3-2 条件区分与反证

优先查：市场机会越稀缺，集中形成是否越突出；同样集中是否只在供给可吸收/成交可执行时带来后续接力。若所有背景同样存在，弱化“熊市机会匮乏”解释；若仅行业利好或交易制度能解释，归相应路径，不硬留本假说。

### V3-3 参与判断（前述完成后）

输出：当前更像集中路径还是扩散路径、依据是什么、可参与资产范围、承接与后续买方是否仍有获利条件、何种观察将推翻判断、置信程度与未知。只有此后才核对进入批次风险/空间/等待，不能“胜率高”直接替代资金判断。

停止/降级：若只有价格/成交结果且无法区分竞争解释，就保留为描述，不晋升机制；若所谓获利方向普遍不可成交，则不作可参与结论；若结论靠单个事件/一个时期，不推广。缺数据先缩小可回答范围，不以无法绝对证明为由全面停止研究。
