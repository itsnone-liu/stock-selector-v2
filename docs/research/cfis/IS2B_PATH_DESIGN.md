# CF-IS Phase 2B 路径验证：首轮实现定义

## 事件视图与候选节点分工

`is2b_event_timeline.py` 仅提供按时点展开的事件及资金变化观察，不是A/B/C介入节点引擎。每条事件保留其当时已公开的同簇成员，后续公告不进入 earlier known ids；分簇只控制依赖解释，不删去升级到缓和的转移。

PRE取事件前严格已可用、距事件不超过21自然日的最近周记录；不以事件周均值代表事前。POST从事件ISO周之后开始，按固定后续交易周，不跳过坏行、不补零。所有POST变量均为事后观察；若以后用它确认介入，要从对应数据可用时点评估未来，不能回到事件时点。

## 三种待验路径

- 压力释放后承接有效，随后扩散：底部修复候选。
- 支持存在而参与长期不足：低位滞留候选，需真实指数、板块/个股宽度及成交活跃度共同判断。
- 新冲击/原有压力持续，低点继续下移：再次破位候选。

本批仍未实现严谨的卖压代理、低点/冲击模型及长期滞留结果定义。不得仅靠融资负流减弱就称卖压出清，或仅靠breadth>0.5称独立承接。融资净变化不是净买入股票，也非强制平仓量。

## 下一步最小可执行研究

1. 在连续周表中补价格低点、周内最大不利变化、下跌日的量价冲击；先用现有数据可表达的描述量，不把未知卖方身份填成险资/散户。
2. 以此前窗口为基准，描述融资收缩是否缓和、支持是否延续、参与和广度能否在事件后维持；不以未来价格挑选“底部起点”。
3. A早期平衡、B接力启动、C修复确认先保存触发依据与真实评估时点，再独立连接4/8/12周结果。比较等待、回撤与空间，不从同一批历史里挑最高收益参数。
4. 官方实体披露/机构配置层仍不足，四层主体推断需证据等级；宏观背景价格序列尚未接入。本批事件观察不能宣称已经建立完整四层模型。
5. 正反例及连续日历比较窗并存，不只叙述2024年9月；事件较少、窗口重叠时按簇/时期报告，不输出显著性与校准概率。

## 本轮贸易链限制

2025-04-04原税委会公告和2025-05-12日内瓦声明属于同一链。4月4日公告载明的34%及4月10日生效安排是当时版本，后续税率变更尚未完整登记，不能视作最终实际执行税率。4月2日美国公告只在4月4日来源中被提及，不倒填为已恢复其原始公开时点。

## 首轮时间线运行记录

11条事件均保留；9条有完整POST4描述窗口、2条因原子可用性未知的周使窗口无效而留空；7条有独立指数价格基准。当前47项CF-IS针对性测试通过（timeline含12项）。

三项观察只指导下一步设计，不作为事件效果：
- 2024年1月降准窗口，EW后四周约-3.92%，全指价格约+3.47%；说明指数与横截面价格代理必须分栏，不能以指数回升认定个股普遍修复。
- 2024年9月关税公告后四周上涨与联储/国内政策窗口重叠，不能据此称关税升级利好；控制事件并存是研究核心难点。
- 2025年6月升级报道与停火回应同ISO周，POST4完全共享（全指约+6.25%）；周频不能辨别同周两个节点各自影响，必须保留不能区分的结论，需要日级证据才讨论时机。

现程序输出数据可见性的保守视图，不代表真实历史可交易面板；原始宏观背景尚未接入，不能计算当前或未来路径概率。
