# KNOWN_DIFFERENCES（复刻版与旧代码的已知差异）

仅列复刻版与旧 EOD 源码行为不同处；均已评估且不改变 900/900 差分结论
（差分样本未触及这些边界，或差异方向已在装置中说明）。

## D1 周二窗口边界

- 旧：`daily[daily.index >= index[-1] - 7天]`，取倒数两根当周一/周二；
  周一为节假日时会把上周五错认成"周一"。
- 复刻：`current_week_rows`（真实自然周行），周一缺勤时以本周首个交易日为周一。
- 影响边界：仅节假日周；方向：复刻更接近语义本意。差分窗口未触发。

## D2 实时版合并周语义

- 旧实时版周一分支把"上周开盘→实时价"当延续中的本周检查（tw_open=上周open）。
- 复刻 EOD 版不含此路径；盘中复刻需另立 source_variant=legacy_realtime。

## D3 回放星期来源

- 旧：运行时真实 `datetime.now().weekday()`。
- 复刻：as_of 的星期。回放当日 EOD 语义时两者一致。

## D4 数据截断

- 旧：TDX 目录当日数据（盘中运行时日线可能缺当日行）。
- 复刻：快照截断 as_of 之前 + quote 合成当日 bar；EOD 回放下等价。

## D5 周线帧构建

- 旧：get_weekly_data 每次重 resample 全量（含当日）。
- 复刻：预计算周线 + 按周一边界切片；差分已验证等价（含部分周行为）。
