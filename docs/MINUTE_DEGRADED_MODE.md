# 盘中分钟数据：降级运行方案（2026-09-16 定稿）

## 决策

用户判断：分钟数据**可得，但非专业付费方案的速率无法支撑即时判断**（实时拉取
频率达不到盘中决策需要）。因此 #6（分钟数据源）正式**搁置**，系统采用本文
所述降级模式运行，不再视为待办阻塞项。

## 降级模式定义（现状即目标态）

| 能力 | 降级模式实现 | 精度代价 |
|---|---|---|
| 量能折算 VolumeClock | `uniform_v0`：盘中量按时间线性折算（10:30≈25%日量） | 尾盘爆量日低估、开盘爆量日高估折算量 → 周一 veto 偶发误判（保守方向：宁可多观察） |
| 退出执行 | 统一 **close-confirm**（T日信号→T+1开盘成交） | E1 intraday 变体不启用（滚动验证本就显示两变体无稳定优劣，33% 复制率） |
| 盘中检查点（14:45） | L1 证据 = 实时 quote（现价+当日累计量）单来源；无分钟文件参与 | 无法历史回放盘中时点（只能 EOD 15:05 回放） |
| 盘中回放 PIT | 不提供（分钟为空时 `quote_from_minutes` 返回 None，`decide` 自动退回无 quote 路径） | 回放仅 15:05 检查点 |
| E1 intraday 回测 | 标记"未校准"，不产出结论 | — |

## 已就位、未来可直接启用的件（升级路径）

代码全部写好并有测试，拿到分钟数据即可解锁，无需重写：
- `decision/minutes.py`：`TdxMinuteReader`（lc1/lc5 32字节解析）+ `SyntheticMinuteProvider`（测试用线性路径）
- `decision/replay.py::quote_from_minutes`：分钟→盘中 Quote（PIT 截断 ≤asof）
- `VolumeClock` 预留 profile 切换：`uniform_v0 → profile_v1`（用真实分时量分布替换线性假设）
- E1 intraday 变体参数已在 `evaluate_exits_streaming` 回测框架里

解锁条件（任一）：① 部署侧（能连 TDX 的机器）同步 lc1/lc5 文件过来；
② 专业付费行情方案（速率达标）；③ 免费源的受限速率被证明够用（仅 EOD 后
下载、不做即时判断——此时只解锁回放与校准，不解锁盘中即时）。

## 风险声明（进 advice/报告的措辞）

降级模式下，盘中（<15:00）产出的建议须携带：
- `volume_method: uniform_v0`（已在 metrics 中）；
- unknowns 含盘中折算近似说明（confidence 规则化扣减已覆盖）；
- 退出执行参考只给"次日开盘"，不给"当日即时"。
