# 交易决策系统蓝图（Decision System Blueprint）

状态：设计定稿待评审 ｜ 日期：2026-09-15 ｜ 基线：`v2.0-ai-rebuild-20260915`（代码冻结）

## 0. 本文档的执行边界

- 目标系统是**交易决策系统**：仓位 → 选股 → 退出 全链条，不确定判断输出"建议"，人拍板。
- 因 A股 T+1，信号必须**盘中可得**，不是盘后。
- 当前阶段**不修改任何现有代码与生产配置**；本蓝图与《语义恢复工作表》是冻结后的第一批交付物。
- ETF 数据源由用户自行考察与订阅，本方案只预留接入契约。

## 1. 目标与非目标

### 目标

1. 盘中任意时点可回答：对某只票/当前组合，现在应该 买入/加仓/持有/减仓/卖出/观望，以及为什么。
2. 每条建议自带证据表、不确定项和失效条件；不确定就明说 `low confidence / unknown`，不伪装成精确分数。
3. 退出与仓位是系统一等公民，不是选股的附件。
4. 全链路可回放、可归因、可审计：任何历史建议能复现"当时看到了什么"。

### 非目标（现阶段）

- 全自动下单（执行接口预留，默认只出建议）。
- 盘中 tick 级/Level-2 策略（最小数据粒度=分钟线+实时快照）。
- 用一个综合分概括一切（已证明总分与收益不单调）。
- capital-observer 变成选股硬门槛（先做上下文证据）。

## 3. 盘中可得：核心语义

### 3.1 as_of 与证据完整度

一切计算以 `as_of`（含毫秒时戳）为唯一时钟。数据分三级：

```text
L0  昨日及以前        完整、可靠（以"当时可得"口径）
L1  当日截至 as_of    部分K线：已实现OHLC + 累计量 + 观测分钟数
L2  当日收盘后        完整（仅用于盘后复核与次日计划）
```

每个信号必须携带证据完整度，禁止把 L1 当 L2 用：

```json
{
  "as_of": "2026-09-16 10:35:00",
  "evidence_level": "L1",
  "session_clock": {"observed_minutes": 125, "total_minutes": 240, "completion": 0.52},
  "volume_view": {"cum_volume": 1230000, "expected_day_volume": 3100000, "method": "u_shape_median_v1"}
}
```

### 3.2 价格不投影，量能按时钟折算

- 价格只用已实现值：`realized_change_pct`、当前价距均线/高低点位置。
- 废除"当前涨幅×5/已过天数=预计周涨幅"的用法，改为 **momentum_velocity = 已实现涨幅 / 周完成度**，仅是速度指标。
- 成交量是累积变量，可折算：`expected_day_volume = 当前累计量 ÷ 该时点历史分时占比(中位)`。折算方法带版本号；同时保留原始累计量。
- 分时占比基准按"星期几×该品种历史分布"建立，样本不足时输出 `expected_day_volume = null` 并降级证据。

### 3.3 决策时刻表

```text
09:25  集合竞价后预检（竞价数据+昨日完整数据；只出 watch/prepare，不出买入）
10:00  检查点1
11:30  午盘小结（午后复评）
14:00  检查点2
14:45  尾盘主决策（证据完成度≈95%+，当日K线接近定型的最早可决策点）
15:05  盘后复核（L2）：成交核对、退出单挂设、次日计划、底部池/形态事件入池
```

- 增量计算粒度工程上取 5 分钟轮询或事件驱动，语义不变。
- 现有 realtime 模式升级为**主语义**；盘后 close 模式退化为 `as_of≥15:00` 的特例。

### 3.4 周级证据的星期语义（与三模式的关系）

weekday 三模式（legacy/unified/revised）都重定义为**以 as_of 当日为临时周K的盘中版本**：

| 时点 | 当日地位 | 规则要点 |
|---|---|---|
| 周一 | 信息最少 | carry_forward 上一完整周状态，有效期至当日收盘；当日出现 distribution_risk 即否决 |
| 周二 | 两日证据 | 双阴缩量 → pullback_weakening（不是买点，是"卖压衰减"观察） |
| 周三四 | 部分周 | momentum_velocity + 量能折算；不预测周涨幅 |
| 周五盘中 | 临时完整度最高 | 仍属 L1，14:45 后证据近似完整 |
| 任何日收盘后 | L2 | 完整周K判定（周五）或周中状态更新 |

字段分离：`momentum_state` × `evidence_origin(current_week/previous_completed_week)` × `evaluation_status(evaluated/insufficient/stale)` × `calendar_weekday` × `trading_session_in_week`（节假日短周单测覆盖）。

## 4. T+1 与执行模型

### 4.1 硬约束

1. 当日买入的份额**次日才能卖** → 盘中买入即承担隔夜风险，建议必须附隔夜风险段。
2. 对持有≥1日的仓位，盘中触发的卖出/止损**当日即可执行** → 退出监控是盘中任务，不是盘后任务。
3. 涨跌停：涨停无法买、跌停无法卖（按可成交性规则处理，见 4.3）。

### 4.2 仓位层默认值（全部可配置，需验证后晋升）

```text
大盘regime（指数 MA20/MA60）:  bull=100%  mid=0~50%  weak=趋势通道停止
单票上限:                      ≤20%（建议值，待组合回测校准）
行业暴露上限:                  ≤40%
单日新增敞口上限:              ≤30%（T+1日内不可撤，限制当日试探总量）
分批机制:                      盘中试探仓(≤半仓) + 14:45尾盘确认加仓
```

### 4.3 可成交性规则（回测与实盘同语义）

```text
买入: as_of时点 若涨停(卖一为空/价格=涨停价) → 标记 buy_blocked，建议降级 watch
卖出: 跌停且无买盘 → sell_blocked，转为次日首务+风险事件记录
停牌/无行情: 不可交易，建议挂起并说明
```

### 4.4 退出管理（候选集，逐项验证后组合）

```text
E1 结构失效: 收盘破买点日低点（底部池=事件日低点）     → 硬风险底线
E2 时间退出: 固定5日（稳健）/10日
E3 移动回撤: 收盘峰值回撤8%（右尾型）
E4 组合A: E1 + E2-5日
E5 组合B: E1 + E3 + 最长持有20日
```

- 触发≠成交：退出模拟必须按触发后可执行价格（次一可成交时点）计算，禁止用触发价当成交价。
- 盘中版本：E3 可用盘中价触发、当日执行（持有≥1日）；E1 默认收盘确认防日内假破，**两种口径都要回测**。

## 6. 回放与验证（PIT + 盘中）

### 6.1 新增关键依赖：分钟级历史数据

盘中可得规则的回测**必须**有分钟级历史（或至少分钟OHLCV聚合），日线数据无法重建"14:45时点看到了什么"。数据源选项：

| 源 | 深度 | 成本 | 备注 |
|---|---|---|---|
| TDX/mootdx 5分钟 | 较浅（约近1-2年） | 免费 | 先用做引擎冒烟 |
| Tushare `stk_mins` | 较深 | 高积分 | 与ETF一并比较套餐时评估 |
| RQData/JQData 分钟 | 深 | 订阅 | 同上 |

**分钟数据源决策与用户的ETF订阅考察合并评估**（一次采购解决两件事可能更划算）。

### 6.2 回放引擎语义

```text
replay(as_of, universe_at_that_time)
→ 截断到 as_of 的可见数据（含 L1 部分K线重构）
→ 全信号链重算（不是读取预计算结果）
→ 建议落盘 → 之后分钟数据驱动成交模拟 → 持仓账本 → 退出监控
```

### 6.3 防穿越测试（必须全绿）

1. 篡改 as_of 之后任何行情 → 历史建议不变；
2. 未来ST/退市变化 → 历史状态不变；
3. 当日后分钟数据 → 不影响当日 10:35 的建议；
4. 周五收盘数据 → 不影响周一 10:00 建议；
5. 单日回放 = 批量回放（确定性）；
6. 同版本重复运行结果逐字节一致（除显式随机数种子外不允许随机）。

### 6.4 报告分级

`引擎PIT通过` → `数据受限实验`（现股票池偏差声明）→ `扩展历史`（退市/ST/复权补齐）→ `可执行组合`（费用+成交约束）。禁止越级宣称。
